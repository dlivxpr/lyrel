<a id="ports-you-did-not-ask-to-forward"></a>
## 无需手动设置的端口转发

当窗格位于远程机器上时，lyrel 会监测其中进程正在监听的端口，并自动为你转发。在远程启动一个监听 `:3000` 的开发服务器，片刻后就会收到通知，提示可通过 `http://localhost:3000` 访问——端口号不变，无需编写规则。

信息面板的**端口**区域会列出所有端口：每个监听端口占一行，显示所属进程，以及在本机上的访问地址。点击地球图标可在浏览器中打开，点击复制按钮可获取本机可用的地址，点击 ✕ 则会停止该转发。

每个端口只会自动转发一次。移除后就不会再次自动转发——每个端口只会触发一次自动转发，而不是每次轮询都触发。

只要本地端口空闲，就会使用与远程相同的端口号。如果该端口已被占用——例如本机已有其他程序占用了 `:3000`——操作系统会另选一个端口，并在对应行中显示。

可在**设置 → 终端 → 链接 → 转发远程端口**中关闭整个功能（`ssh_loopback_forward: false`）。

<Note>
  在远程工作区中，端口由**远程机器上的 `lyrel-server`** 发现——这些窗格归它管理，本机守护进程并不知道它们的存在。如果服务器版本过旧，无法响应查询，端口区域会明确提示，而不是显示空列表；更新服务器即可解决。从本地窗格内部通过 ssh 连接到其他机器的情况则不同：那些进程不归任何 lyrel 服务器管理，因此不会被列出。
</Note>

<a id="the-three-kinds"></a>
## 三种转发类型

| | 作用 |
|---|---|
| **本地**（`L`） | 通过本机上的端口访问远程的服务 |
| **远程**（`R`） | 通过远程机器上的端口访问本机的服务 |
| **动态**（`D`） | 在本机提供 SOCKS 代理，流量经由该连接转发 |

<a id="adding-one-to-a-profile"></a>
## 在配置档案中添加转发

**设置 → SSH →** 选择配置档案 **→ 端口转发 → + 添加规则**。保存在此处的规则会在每次建立连接时启用。

本地或远程规则需要监听端口和目标；动态规则只需要监听端口。规则不完整时会给出提示，而不会保存尚未配置完整的规则。

每条规则都可以添加可选的描述，说明*“它的用途”*——毕竟六个月后，单看 `8080 → 3000` 根本想不起它是做什么的。

<a id="adding-one-mid-session"></a>
## 在会话期间添加转发

点击端口区域中的 **+**，或在全局搜索中选择 *SSH：端口转发*，即可打开表单，只需填写一项：远程服务正在使用的端口。本机会使用相同的端口号，表单也会在你确认前明确说明这一点。

点击**高级**可展开其余配置：远程和动态转发、回环地址以外的绑定主机、位于第三台机器上的目标，以及描述。需要这些选项的频率，大概和需要 `ssh -R` 的频率差不多。

这些转发仅在当前会话期间有效，除非将它们保存到配置档案中。

<a id="switching-a-rule-off"></a>
## 关闭规则

端口区域中的每条转发都有一个开关。关闭后，转发会释放端口，但保留完整规则——类型、端口、目标和描述——因此再次开启时无需重新输入任何内容。通过这种方式，可以让同一个本地端口指向不同位置：为每个目标各保留一条使用相同端口的规则，再开启需要的那一条。

同一时间只能有一条规则占用该端口。如果另一条转发仍占用端口，开启操作就会被拒绝，通知中会指出需要先关闭哪条转发。

来自配置档案的规则会将开关状态保存回档案，因此下次连接时会启用同一组规则。在**设置 → SSH →** 选择配置档案 **→ 端口转发**下，每条规则旁也有相同的开关；保存时处于关闭状态的规则会列在其中，但不会启用。在会话期间添加的规则，无论开启还是关闭，都会在会话结束时消失。

<a id="links-in-the-terminal"></a>
## 终端中的链接

在远程窗格中按住 <kbd>⌘</kbd> 点击 `localhost:PORT` 链接时，如果该端口尚未转发，就会先建立转发，再打开浏览器。它使用与端口列表相同的机制，只是入口从面板变成了终端输出。

<a id="jump-hosts-and-proxies"></a>
## 跳板机和代理

多跳连接按配置档案分别设置：

- **跳板机**——指向另一个已保存的配置档案，或使用 `ProxyJump` 链
- **ProxyCommand**——任意传输命令，其中的 `%h`、`%p`、`%r` 会被替换
- **SOCKS5 代理** / **HTTP 代理**——在**高级 → 代理**中填写 `host:port`

<Note>
  这些代理设置用于连接 SSH 服务器。lyrel *自身*的网络流量——更新检查、发行包下载、远程服务器安装——使用 `config.json` 中的 `http_proxy`、系统代理或 `HTTP_PROXY` 系列环境变量。窗格中运行的程序不受这两类设置影响；与任何终端一样，它们从自身环境中继承代理配置。
</Note>
