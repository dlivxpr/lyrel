title: "SFTP"
description: "浏览连接另一端机器上的文件。"

当窗格处于 SSH 会话中时，通过“全局搜索”中的 *SSH：远程文件*，即可在窗格上方滑出文件面板。它是真正的 SFTP 客户端，复用同一条连接，无需再次登录或再次输入密码。

<a id="browsing"></a>
## 浏览

面板会在窗格中 shell 当前所在的目录打开。如果 lyrel 无法确定该目录（远程 shell 未报告其目录），则会打开你在该窗格中上次浏览的文件夹；首次使用时则打开远程主目录。面板打开时，在窗格之间切换会恢复各个窗格上次浏览的文件夹。溢出菜单中的**转到 Shell 目录**可让你随时跳回 shell 所在的目录。

右键单击某一行，可选择**编辑**（目录对应的是**打开**）、**下载**、**跟随符号链接**、**重命名**、**chmod…** 和删除。溢出菜单还提供**新建文件夹**、**新建文件**、**上传…** 和**刷新**。

<a id="editing"></a>
## 编辑

与本地文件树中的操作相同，单击文本文件即可在[内置编辑器](/window/side-panel)中打开；保存时会通过同一条连接直接写回文件。对于编辑器无法处理的文件（二进制文件或超过 4 MB 限制的文件），面板会给出提示；请右键单击 → **下载**来获取这些文件。

<a id="transferring"></a>
## 传输

| 方向 | 操作方式 |
|---|---|
| 下载 | 右键单击 → **下载** |
| 上传 | **上传…**，或将文件拖入面板 |

上传时会先使用临时文件名写入，完成后再重命名为目标名称，因此传输到一半的文件不会看起来像已完成的文件。如果目标名称已被占用，替换前会先询问。

溢出菜单中的**传输历史记录**会显示每次传输及其进度，并允许你取消正在进行的传输。面板标题栏会汇总当前状态，例如 *“2 项正在传输 · 64%”*。

<a id="permissions"></a>
## 权限

**chmod…** 接受八进制权限模式（`755`、`600`）。修改前，行内编辑器会显示当前权限模式。

<Tip>
  对于[远程工作区](/remote/workspaces)中的文件，通常完全不必使用 SFTP：“文件”面板会直接通过连接读写文件，内置编辑器也会将更改保存回远程机器。
</Tip>
