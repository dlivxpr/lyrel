title: "SFTP"
description: "浏览连接另一端机器上的文件。"
---

通过 lyrel 的 SSH 主机入口建立连接后，“文件”面板使用真正的 SFTP 客户端，复用同一条连接，无需再次登录或再次输入密码；也可通过“全局搜索”中的 *SSH：远程文件* 打开。

<a id="browsing"></a>
## 浏览

面板会在窗格中 shell 当前所在的目录打开，并跟随同一窗格后续报告的目录变化，包括同一仓库内的子目录和仓库外的目录。手动浏览其他文件夹不会被未变化的 shell 目录反复拉回；shell 下次报告不同目录时才恢复跟随。切换窗格时，如果该窗格的 shell 目录未变化，会恢复上次浏览的文件夹；如果已变化，则打开新目录。溢出菜单中的**转到 Shell 目录**可让你随时跳回 shell 所在的目录。

如果 lyrel 无法确定目录（远程 shell 未报告其目录），则打开该窗格上次浏览的文件夹；首次使用时打开远程登录目录。目录跟随依赖 [shell 集成](/reference/shell-integration) 或远端 daemon 的 cwd 报告；缺少报告时不会通过终端文字猜测目录。

在本地 shell 中自行输入 `ssh` 是另一条路径：lyrel 只显示该进程的终端输出，并没有可复用的应用管理 SSH／SFTP 连接，因此不能自动浏览目标机器的文件。即使远端报告 `OSC 7` 路径，也不会把它当成本机路径打开。要使用远端文件面板，请使用 lyrel 的 SSH 主机入口，或打开[远程工作区](/remote/workspaces)。

右键单击某一行，可选择**复制**、**粘贴**、**编辑**（目录对应的是**打开**）、**下载**、**跟随符号链接**、**重命名**、**chmod…** 和删除。溢出菜单还提供**新建文件夹**、**新建文件**、**上传…** 和**刷新**。

**Ctrl 点击**可切换多选（macOS 使用 Cmd），**Shift 点击**选择连续范围；修饰键选择不打开文件或进入目录。右键已选项保留整个集合。**Ctrl+C／Ctrl+V**（macOS 使用 Cmd）或右键菜单复制、粘贴实际文件和目录；粘贴到目录行时以该目录为目标，键盘粘贴以当前目录为目标，名称冲突先确认。复制保留来源连接，不把远端路径当成本机文件；单个文件仍受控制帧大小限制，大文件请使用下载／上传传输。

**Delete**（macOS 使用 Cmd+Backspace）批量删除选中项。确认框列出主机、数量与完整路径；取消不改动文件，部分失败会保留成功结果并报告失败路径。离开目录或切换 SSH 窗格后，旧确认不能通过新连接删除文件。

“文件”页签可见时，浏览器沿既有传输轮询约每两秒在后台重新读取当前目录；远端 shell、智能体或其他进程的新建、重命名和删除会自动反映到列表，不需要手动刷新。慢连接会延长刷新间隔，同一轮询不会堆积多个目录请求。

后台检查不显示导航加载状态、不重置滚动位置；正在编辑文件名或路径时暂缓更新，保留输入。目录未变化时不触发重绘，读取失败时保留旧列表，后续轮询继续检查。关闭或隐藏“文件”页签、切换窗格、导航到其他目录或重连后，旧请求不能覆盖当前目录；面板内自身的新建、重命名、删除和上传完成仍使用即时刷新。

<a id="editing"></a>
## 编辑

与本地文件树中的操作相同，单击文本文件即可在[内置编辑器](/window/side-panel)中打开；保存时会通过同一条连接直接写回文件。对于编辑器无法处理的文件（二进制文件或超过 4 MB 限制的文件），面板会给出提示；请右键单击 → **下载**来获取这些文件。

<a id="transferring"></a>
## 传输

| 方向 | 操作方式 |
|---|---|
| 下载 | 右键单击 → **下载** |
| 上传 | **上传…**，或将文件拖入面板 |

上传时会先使用临时文件名写入，完成后再重命名为目标名称，因此传输到一半的文件不会看起来像已完成的文件。如果目标名称已被占用，替换前会先询问。

溢出菜单中的**传输历史记录**会显示每次传输及其进度，并允许你取消正在进行的传输。面板标题栏会汇总当前状态，例如 *“2 项正在传输 · 64%”*。

<a id="permissions"></a>
## 权限

**chmod…** 接受八进制权限模式（`755`、`600`）。修改前，行内编辑器会显示当前权限模式。

<Tip>
  对于[远程工作区](/remote/workspaces)中的文件，通常完全不必使用 SFTP：“文件”面板会直接通过连接读写文件，内置编辑器也会将更改保存回远程机器。
</Tip>
