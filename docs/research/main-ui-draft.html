设置现有独立窗口

设置界面保持当前实现

本会话只重新设计主界面。真实行为仍然是打开现有独立设置窗口，不改变设置页的信息架构、导航或控件。

当前设置窗口960 × 700

设计决策

这是可交互 HTML 初稿，不是生产样式补丁。颜色只表达 lyrel 语义 token；生产实现仍应从 cx.theme() 与 src/ui/presets.rs 取色。

本轮已调整

  • 中央顶栏保持移除；当前目录、分支、主机状态、设置与通知保留在 26px 全局状态栏，状态栏中央不放置常驻文字。
  • 设置在状态栏最左侧且只保留图标；通知在状态栏最右侧。
  • 左右两组三按钮使用同一种圆角控件组；左栏第一行是 lyrel 图标和左侧三按钮，第二行是工作区切换按钮。
  • lyrel 图标是窗口级元素；左侧栏收起后仍保留在窗口左上角，左侧三按钮组向右让位。
  • 左侧组顺序为“收起左侧栏 / 随处搜索 / 新建标签页”；右侧组顺序为“向右分屏 / 向下分屏 / 收起右侧面板”。
  • 工作区切换按钮沿用当前界面形态：圆形首字母头像、工作区名和上下切换箭头。
  • 窗口控制“最小化 / 最大化 / 关闭”上移为窗口级常驻控件；右侧面板收起后仍保留在窗口右上角。
  • 分屏按钮沿用当前产品右键菜单语义：从当前 pane 向右侧或下侧新增一个终端，快捷键分别为 Ctrl+Shift+D 与 Ctrl+Alt+Shift+D。
  • 切换或新建标签页不向状态栏中央写“已切换”提示。
  • 侧栏收起后仍保留对应三按钮：左侧组浮在窗口左上角，右侧组浮在窗口右上角；不显示缩小版侧栏内容。
  • 工作区切换按钮位于左栏第二行并占满可用宽度。
  • 随处搜索使用 macOS Command 图形；左栏内重复的“筛选标签页”输入框移除。
  • 右侧“信息 / 文件 / 更改 / GitHub”保持独立页签行，位于右侧面板开关下方。
  • pane 抓手只在指针接近 pane 顶部时出现；点击打开命令菜单，拖动移动窗格。
  • 底部 park 改为可放多个窗格的紧凑牌堆；静止时牌堆底部与状态栏顶边对齐、不进入状态栏，悬停时出现暖色半圆光环，只有指针下的牌抬升、转正并放大，其他牌仍贴近底部。
  • 点击某张停放牌会翻面并放大为预览，背面显示标题、路径和“恢复”按钮；点击牌堆外部或按 Esc 关闭预览。
  • 拖拽进入底部 park 时显示暖色大半圆和顶部 Park 胶囊，不再使用虚线小框。
  • 底部 park 落点参考 tern 截图与录屏；官方 Stencil Tern 文档中可核实的对应能力是 pip stash 与 PiP deck/fan 类交互，不是名为 park 的公开命令。
  • 设置预览不再重绘设置界面，只说明按钮仍打开现有独立设置窗口。

pane 菜单来源

命令名以 Stencil Tern Built-in Actions 为依据；菜单中可见的快捷键来自用户给出的 tern 截图，只是原型占位，不能当作官方默认绑定。Stencil 官方文档可核实 split_right、split_down、pip 与 pip stash，但没有把 park 定义成公开 pane 命令。

实现边界

  • HTML 的 backdrop-filter 只是近似；GPUI 真实实现应使用整窗 WindowBackdrop，不做左右栏独立模糊。
  • park 卡片表达“PiP 贴边暂存后留下的恢复入口”；底部落点来自截图观察，官方文档只明确左／右边缘 stash。
  • HTML 用 rotateY 表达翻面；GPUI 若没有等价 3D transform，生产实现应改为水平压缩、交换前后两面、再展开的等效动画。
  • park 与 PiP 只改变 pane 的可见布局，不复制或停止终端会话；若只剩一个 pane，真实实现应禁用 PiP。
  • CPU 与 MEM 是小组件示意，不表示第一版已有采集实现。

验收路径

  • 左栏第一行是 lyrel 图标和圆角三按钮组“收起侧栏、随处搜索、新建标签页”；第二行是整宽工作区切换按钮。
  • 工作区切换按钮包含圆形 D 头像、dlivxpr 和上下切换箭头。
  • 右侧面板顶部是圆角三按钮组“向右分屏、向下分屏、收起右侧面板”，不再与窗口控制按钮重叠。
  • 初始只有一个终端；点击“向右分屏”会在当前 pane 右侧新增终端，点击“向下分屏”会在当前 pane 下方新增终端。
  • 连续分屏会相对当前激活 pane 插入新终端；pane 菜单中的两个分屏命令与当前产品右键菜单同名同快捷键。
  • 收起左栏后，lyrel 图标仍留在窗口左上角，左侧三按钮组位于图标右侧；收起右栏后，右侧三按钮组浮在窗口控制按钮左侧。
  • 停放多个窗格后，牌堆与扇形光环的实际包围盒都不越过状态栏顶边；悬停时扇形展开，点击其中一张会翻面放大并显示“恢复”。
  • 点击某张牌的“恢复”只恢复该窗格；其余停放窗格仍保留在底部牌堆。
  • 切换或新建标签页时，状态栏中央不出现“已切换”或“已新建”提示。
  • 左栏没有“筛选标签页”输入框；状态栏中央默认没有常驻文字。
  • 指针进入 pane 顶部 36px 才显示抓手；点击抓手打开菜单。
  • 从抓手拖到底部圆形落点会停放 pane；点击底部卡片恢复。
  • pane 菜单的“画中画”会把窗格浮到右下角卡片；卡片可停放到底部或还原为分屏。
  • 文件铺满时无中央顶栏，目录与文档状态仍在全局状态栏。
