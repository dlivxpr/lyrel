## 标签页

| | |
|---|---|
| <kbd>⌘ T</kbd> | 新建标签页 |
| <kbd>⌘ W</kbd> | 关闭标签页（如果标签页有多个窗格，则关闭聚焦的窗格） |
| <kbd>⌘ ⇧ T</kbd> | 重新打开刚刚关闭的标签页 |
| <kbd>⌘ 1</kbd> … <kbd>⌘ 9</kbd> | 跳转到标签页 1–9 |
| <kbd>⌃ ⇥</kbd> · <kbd>⌃ ⇧ ⇥</kbd> | 按住可向前或向后浏览切换器；松开时选定 |

新标签页总是在当前窗格所在的目录中打开。它在列表中的位置由
**设置 → 常规 → 新标签页位置**决定——默认为*当前之后*，或*末尾*。

右键点击标签页可进行其余操作：重命名、向右或向下拆分、新建工作树标签页、
复制工作目录、复制会话 ID、关闭 · 关闭其他标签页 · 关闭右侧标签页，
以及——如果其中有编程智能体正在运行——标记为未读并派生其会话。

### 全局状态栏中的主机指标

终端工作流右侧的 CPU／MEM 测量当前工作区所属的整台主机，与标签页、窗格和 PiP 的焦点无关。
本地工作区由本机 daemon 后台读取系统整机 CPU 和物理内存，CPU 按全部逻辑核归一化至 0–100%，
MEM 显示系统定义的已用 RAM 比例，不含 swap；悬停可查看实际主机名及已用／总 GiB。

首次 CPU 采样显示等待；断开、不可用或采样失败时显示明确状态，不用 0% 代替缺失数据。
远端工作区通过远端 daemon 测量整台远端主机，悬停可查看它报告的真实主机名。
连接中与重连中明确显示；服务器不支持指标时显示不可用，不读取本机代替。切换主机时不会把上一台机器的数值改标为新主机。
文档工作流使用文档状态替换这些终端指标；设置、时钟及全局通知入口仍保留。


<a id="splits"></a>
## 分屏

| | |
|---|---|
| <kbd>⌘ D</kbd> | 向右拆分 |
| <kbd>⌘ ⇧ D</kbd> | 向下拆分 |
| <kbd>⌘ ]</kbd> · <kbd>⌘ [</kbd> | 下一个窗格 · 上一个窗格 |
| <kbd>⌘ ⌥ ← → ↑ ↓</kbd> | 聚焦该方向的窗格 |
| <kbd>⌘ ⇧ ⏎</kbd> | 将聚焦窗格缩放至填满标签页 |
| <kbd>⌘ ⏎</kbd> | 将窗口全屏 |

拆分出的窗格会继承当前窗格的工作目录，因此在仓库内拆分后，你仍停留在该仓库中。

调整窗格大小和交换窗格没有默认快捷键——可在**设置 → 按键绑定**中绑定，
或从全局搜索运行它们（*Resize Pane Left*、*Swap Pane Next* 等）。

非活动窗格会略微变暗，让聚焦的窗格一目了然。可通过
**设置 → 外观 → 调暗非活动窗格**关闭此效果。

<a id="pane-menu"></a>
### 窗格菜单

菜单始终针对打开它的窗格，而不是之前聚焦的窗格。焦点位于窗口控件时，可用 <kbd>Tab</kbd>
聚焦手柄、<kbd>Enter</kbd> 打开菜单，方向键选择，<kbd>Escape</kbd> 关闭并返回此窗格。
终端内的 <kbd>Tab</kbd> 继续发送给 shell；无需悬停的命令入口是随处搜索和已配置的快捷键。
菜单中的快捷键取自当前平台和用户绑定；未绑定的操作不显示示例快捷键。

- **粘贴、向右／向下分屏**：复用终端粘贴路径；分屏继承该窗格的 shell、机器和目录，
  连续分屏相对于新聚焦的窗格进行。
- **将窗格移入画中画／将画中画恢复到分屏布局**：改变同一个终端的呈现方式；不会复制会话、重启 shell 或关闭窗格。
- **停放窗格（Park）**：将此平铺或画中画窗格放入当前标签页的底部牌堆，Shell 与智能体继续运行；不是关闭或休眠。
- **缩放窗格**：只改变标签页内的显示范围，再次执行恢复分屏；不改变终端或界面字号。
- **移至新标签页**：移动原窗格和运行中的会话，不新建 shell；只有一个窗格时不可用。
- **在滚动历史中查找**：打开该终端原有的查找栏。
- **在编辑器中打开滚动历史**：把保留的历史与屏幕文字作为可编辑、可另存为的未保存文档打开，
  保留 Unicode，去掉终端控制序列；不在远端或本地隐式创建临时文件。
- **清屏**保留滚动历史；**清屏和滚动历史**同时清除两者。这两个操作不会重启程序。
- **重启 shell…**：确认后终止此窗格的进程，在同一台机器、同一目录用原 shell／SSH 配置重建。
  远端连接不可用时不会改为本地 shell。其他窗格不受影响。
- **关闭窗格**：沿用忙碌进程与未保存文档的保护；最后一个窗格会关闭其标签页。

上述命令也可从全局搜索运行，或在设置里为 `MovePaneToTab`、`OpenScrollbackInEditor`、
`ClearPaneScreen`、`RestartPaneShell` 绑定快捷键；这些新操作没有默认快捷键。

<a id="picture-in-picture"></a>
### 标签页内的画中画

每个标签页最多保留一个画中画（PiP），初始位于终端内容区右下角，不进入全局状态栏。
它仍是可输入、选择文字和滚动历史的原终端；终端视图只在分屏或画中画中绘制一次。
只有一个窗格时也能移入画中画，中央分屏区可以为空，不会为了填满空白自动启动 shell。

选择另一个窗格进入画中画，会先恢复原画中画，再浮起新选择的窗格。恢复只调整目标窗格，
保留期间新建、移动或关闭的其他分屏；优先使用原分屏关系，原位置失效时返回当前窗格旁，
没有其他分屏时填满内容区，不读取旧标签页快照覆盖当前布局。

画中画属于标签页，切换标签页或工作区不会把浮窗带到别处。它的选择与恢复关系由所属机器的
daemon 保存，GUI 重开或另一个客户端连接同一工作区后仍保留；键盘焦点与临时交互不共享。
这里的重开指 daemon 仍运行；重启 daemon 不保证原进程继续。CLI 仍可通过同一 pane ID
发现窗格、发送输入和捕获输出，不需要画中画专用命令。

画中画共享状态只交给实际拥有会话的 daemon。本地及远端机器的普通终端使用各自机器布局；
远端工作区额外打开的客户端本地原生 SSH 继续由本机 daemon 管理。它与远端 pane 使用带所有权的
身份，本机 daemon 另外保存远端工作区的组合布局、画中画与恢复关系，避免相同 `pane_id` 相互误操作。
同机 GUI 重开或另一客户端连接时，重新挂载原本机 SSH 会话而不重拨连接；远端布局仍由远端 daemon
同步。另一台机器不能接管本机进程。拆分、移动与显式关闭按操作合并，旧快照不会回滚更新的窗格。
远端最后一个窗格被关闭或移至别处时，只移除该远端分支；组合标签页中仍存在的本机 SSH 窗格及其
停放／画中画状态继续保留。显式关闭整个标签页才清理整个组合，旧的组合快照不会使已关闭的标签页重现。

全局搜索提供 `TogglePanePip` 与 `RestorePanePip`，也可在设置中绑定快捷键；默认不占用新快捷键。
拖动画中画左上的移动手柄调整位置，拖动右下角调整大小；这两个手柄不抢终端输入焦点。
从窗口控件用 Tab 聚焦手柄后可用方向键调整，Enter 或 Escape 返回原终端。最小尺寸随界面字号变化；
窗口或侧栏缩小时仍完整留在状态栏上方。位置与大小的比例意图随工作区保存，换窗口时重新适配，
不会把当前客户端的悬停、焦点或未完成手势传到另一个客户端。

<a id="parked-panes"></a>
### 停放牌堆与恢复

从窗格菜单选择 **停放窗格（Park）**，即可暂时收起同一个运行中的终端。停放牌堆位于终端内容区底部、
全局状态栏上方；切换标签页或工作区时，显示对应标签页的牌堆。最后一个窗格也可以停放：
标签页和恢复入口保留，中央平铺区为空，不自动启动一个占位 Shell，也可显式新建窗格。

也可以拖动窗格顶部手柄到底部：靠近内容底边时出现暖色大半圆和 **停放／Park** 胶囊，进入半圆后
轮廓与胶囊加强，释放左键即停放该窗格。半圆外接矩形的空角和全局状态栏不是落点；
在仍显示的底部停放区域空角释放会取消手势，不意外变成分屏重排。
平铺、最后一个窗格和已缩放窗格支持拖动顶部手柄；PiP 可拖动左上移动手柄至同一目标。
它们与菜单使用同一个停放操作，原会话和 pane ID 不变。

移出目标会撤掉停放反馈；在其他有效区域释放仍可执行普通重新排列或 PiP 移动，在无效位置释放则
不切换呈现模式。按 <kbd>Escape</kbd>、离开窗口、窗口失活或切换标签页会取消未提交手势，
不意外停放、关闭或复制终端。目标始终随内容区域和界面字号适配，不覆盖状态栏或旁边的侧栏。


静止时卡片紧凑叠放，悬停时展开为暖色扇形；只有当前指向的卡片抬起、拉直并放大。
选中一张卡片会翻面打开预览，显示真实标题、路径和 **Restore**。预览不是可输入的终端，
不会接收 Shell 按键。<kbd>Escape</kbd> 或点击外部关闭预览并返回合适的焦点，不会恢复或关闭会话。

**Restore 只恢复选中的窗格**，其他卡片保持停放。优先返回原分屏关系，不撤销期间新增、移动、
关闭或调整的其他分屏；原相邻窗格已经失效时，放到当前有效平铺窗格旁。没有其他平铺窗格时，
第一张恢复的卡片铺满内容区。从 PiP 停放也恢复到平铺，不自动重建浮窗。

停放归所属机器的 daemon 管理，与原工作区、标签页、pane ID 和会话所有权一起保留。
GUI 重开或另一个客户端连接时共享停放及恢复关系，但悬停、翻面预览、焦点与动画进度只在本地，
不随布局同步。CLI 仍可用原 `%PANE` 列出窗格、发送输入和捕获输出。
已退出的会话恢复后仍是退出状态；明确关闭会删除对应卡片，过期的恢复操作不会复活它或误关其他窗格。
daemon 重启仍遵循既有恢复规则，停放不保证原进程跨 daemon 重启存活。

`ParkPane` 与 `RestoreParkedPane` 可从随处搜索运行或自行绑定，均没有默认快捷键。
后者先打开当前牌堆第一张卡片的键盘预览，再通过卡片的 **Restore** 恢复所选窗格，
不会一次恢复全部卡片。

停放总数没有上限。内容区不再能舒适展开全部卡片时，右下角显示 **更多…**：判断依据是当前
内容区宽度、界面字号以及卡片与按钮的可用命中区，不是固定的停放数量。展开或收起侧栏、
调整窗口或放大界面后会重新计算，不会无限压缩卡片。

**更多…** 打开当前标签页的全部停放窗格列表，原生滚动条支持查找列表外的项；每项保留真实
标题、路径与运行／退出／连接状态，长标题和路径可通过提示查看。用 <kbd>↑↓</kbd>、
<kbd>Home</kbd>／<kbd>End</kbd> 或 <kbd>Page Up</kbd>／<kbd>Page Down</kbd> 选择，
<kbd>Enter</kbd> 打开同一张卡片的翻面预览，再按 <kbd>Enter</kbd> 恢复该窗格。
鼠标点击列表项同样先预览，不会误恢复相邻项。也可先用 `RestoreParkedPane` 进入牌堆，再用
方向键到达牌堆外的项，自动打开列表。

从列表打开预览后，第一次 <kbd>Escape</kbd> 返回列表，再次按下才关闭列表并归还焦点；
若窗口变宽使原「更多」入口不再需要，则返回仍有效的牌堆。其他客户端删除当前项会关闭失效
预览，不会把恢复请求改投另一张卡片。列表、卡片和命中区始终留在内容区，不覆盖全局状态栏。



<a id="rearranging-by-dragging"></a>
## 拖动重新排列

每个窗格顶部有较大的圆角手柄，鼠标进入顶部感应区或键盘聚焦时显现，菜单打开时保持可见。
单窗格和缩放后的窗格也保留此入口；感应区叠加在终端上方，不永久挤占输出空间。
点击打开此窗格的菜单；拖动可停放，标签页中有多个平铺窗格时还可重新排列，不会顺带打开菜单。

放置的位置决定会发生什么：

<AccordionGroup>
  <Accordion title="放在窗格的侧边">
    窗格会落在该窗格的**旁边**。如果它面对的是同一行或同一列中的邻居，
    就会加入那一行或那一列，并分得相等的一份。只有当它横跨布局相对——
    没有可加入的行或列时——才会将那个窗格一分为二。
  </Accordion>
  <Accordion title="放在窗格的中间">
    两个窗格**互换位置**。
  </Accordion>
  <Accordion title="越过窗格的外侧">
    最外缘之外的那条带状区域——朝向窗口而不是朝向另一个窗格的一侧——
    会让被拖动的窗格成为其他所有内容旁边的一条全宽或全高带状窗格，
    大小等于该侧现有内容平均分得的一份。2×2 布局中间的一个窗格，
    一次拖动就会成为全高的*第三*列，而不是占据半个窗口。
  </Accordion>
</AccordionGroup>

拖动时落点会亮起，而且只有在放置确实会改变布局时才会亮起。

<a id="making-one-tab-a-pane-of-another"></a>
## 将一个标签页变为另一个标签页的窗格

你反复切换的两个会话应该待在同一个标签页里。拖动一个标签页——抓住它在
标签栏中的标签块，或它在侧边栏中的行——拖到窗格区域上方，然后放到你想要
的位置：它会成为你正在查看的标签页中的一个窗格，而它原来所在的标签页会消失。

落点提示与拖动窗格时完全一致，只是没有中间区域：标签页在这里没有可以互换
位置的对象，因此窗格中间的含义是“沿着最长的方向拆分它”。本身已被拆分的
标签页拖入后，其窗格仍保持你离开时的排列，并分得所加入那一行或那一列中
的一份空间。

整个移动过程中不会有任何东西重启。处在命令执行中途的 shell、SSH 会话，
以及一轮任务进行到一半的编程智能体——它们都会继续运行；消失的只是它们
原来所在的标签页。标签页的*名称*不会一起带过去。

拿起标签页并不会切换到它，因此你拖入的标签页就是你原本正在查看的那个。
普通点击仍和以往一样会切换标签页。

<a id="making-a-pane-a-tab-of-its-own"></a>
## 将窗格变为独立的标签页

反向的相同操作。抓住窗格的拖动手柄，拖到左侧标签导航；
插入光标会显示它将插入哪两个标签页之间。
放开后，它会离开原有的拆分，在该位置成为独立的标签页。

这里同样不会有任何东西重启。标签页中的最后一个窗格无处可去，因为它本身
就已经是一个独立的标签页，所以不会为它显示插入光标。

<a id="closing-something-that-is-busy"></a>
## 关闭仍在忙碌的内容

关闭仍有命令在运行的窗格或标签页时，会先询问，并说明正在运行什么：
*"cargo 还在运行，关闭会终止它。"* 如果编程智能体正在处理一轮任务，
则会改为提示——*"omp 还在工作，关闭会中断这一轮。"*

<a id="where-the-tabs-live"></a>
## 标签页的位置

标签页只位于左侧[侧边栏](/window/sidebar)，不再在 Settings 中切换横向模式。升级会仅移除 `tab_bar_position` 与失效的 `auto_hide_titlebar_buttons` 配置键，不重置主题、字体、透明度、快捷键或工作区数据。

窗口右上角常驻向右分屏、向下分屏、右侧面板开关三个按钮，与原生窗口按钮分开。分屏始终相对于当前活动窗格；连续分屏从新激活的窗格继续。右侧面板收起、左侧栏收起或文档铺满时，这些按钮仍保留。信息、文件、更改、GitHub 是右面板下方独立的页签行，不与窗口控件混排。

<kbd>⌘ B</kbd> 显示或隐藏侧边栏；<kbd>⌘ J</kbd> 显示或隐藏右侧的
[侧面板](/window/side-panel)。
