<kbd>⌘ P</kbd>（Windows 上为 <kbd>Ctrl ⇧ P</kbd>）可打开全局搜索。输入文字进行筛选，使用 <kbd>↑</kbd> <kbd>↓</kbd> 移动，按 <kbd>⏎</kbd> 执行，使用 <kbd>⇥</kbd> / <kbd>⇧ ⇥</kbd> 在搜索标签页之间切换。再次按下该快捷键或按 <kbd>Esc</kbd> 即可关闭。

<a id="tabs"></a>
## 标签页

| 标签页 | 包含的内容 |
|---|---|
| **全部** | 从下方各标签页中选出的若干最佳结果，分别列在对应的标签页名称下。包含最佳匹配结果的标签页排在最前，因此按 <kbd>⏎</kbd> 始终会执行所有结果中的最佳匹配项。如果某个标签页的结果无法全部显示，点击“*……中还有 N 项*”这一行即可打开该标签页，同时保留已输入的查询。 |
| **操作** | lyrel 能执行的所有操作，无论是否绑定了快捷键——这是访问那些特意未绑定快捷键的操作（如调整窗格大小和交换窗格）的最快方式。 |
| **终端** | 所有工作区中打开的每个标签页，优先显示当前窗口中的标签页，并按最近使用顺序排列；之后列出新建标签页的所有方式：本机安装的 shell（*Shell：zsh*）以及 `PATH` 中的编程智能体（*智能体：omp*）。 |
| **会话** | 本机上的历史编程智能体会话——先列出在当前聚焦标签页目录中运行过的会话，再列出其余会话，均按从新到旧的顺序排列。按 <kbd>⏎</kbd> 可恢复会话。 |
| **主机** | 已保存的 SSH 主机，按使用频率从高到低排列——以及你输入的任意地址。 |

未输入任何内容时，**全部**会优先列出当前窗口中的其他标签页，最近使用的排在最前，因此按 <kbd>⌘ P</kbd> <kbd>⏎</kbd> 即可返回刚才所在的标签页。接着，*操作*下会显示你最常执行的操作，*会话*下则显示最近在此目录中运行的几个智能体会话。

<a id="actions"></a>
## 操作

未输入任何内容时，“操作”标签页会在*最近使用*下列出最常用的操作，然后按组列出其他所有操作——这些分组就像应用的功能地图：

| 分组 | 示例 |
|---|---|
| **标签页与窗格** | 新建标签页 · 新建工作树标签页… · 向右拆分 · 缩放窗格 · 聚焦左侧窗格 · 向上调整窗格大小 · 与下一个窗格交换 · 重新打开已关闭的标签页 · 复制工作目录 · 派生会话 |
| **工作区** | 新建工作区… · 切换工作区… · 重命名工作区… · 停止工作区… · 删除工作区… |
| **视图** | 显示/隐藏左侧边栏 · 显示/隐藏右侧面板 · 显示代码面板 · 标签栏：移至顶部 · 右侧面板：信息 / 文件 / 搜索 / 更改 / GitHub · 更改主题… · 进入全屏 · 切换统一 / 并排差异视图 |
| **Git** | 提交 · 暂存所有更改 · 取消暂存全部 · 丢弃全部 · 创建分支… · 同步 · 推送 · 拉取 · 获取 |
| **终端** | 清除回滚缓冲区 · 在终端中查找… · 查找下一个 / 上一个 · 复制 · 剪切 · 粘贴 · 全选 |
| **SSH** | 添加连接… · 管理配置档案… · 重新连接 · 远程文件 · 端口转发 |
| **智能体** | 新建智能体标签页 · 发送选中内容 · 发送 Git 差异以供审查 · 复制会话 ID |
| **应用** | 设置… · 键盘快捷键 · 检查更新… · 文档 · 项目主页 · 报告问题… · 重启服务器… |

会执行破坏性操作的条目，会在名称下方明确说明——*删除工作区…*的副标题为“结束其中的 shell 并忘记布局”，*重启服务器…*的副标题为“结束所有正在运行的 shell；保留布局”。

每项操作都可以通过 lyrel 支持的任意语言中的名称找到，因此使用英文查询也能找到中文或日文标签。

**更改主题…**会在原处打开主题列表：在列表中移动时，会在窗口中预览各个主题；按 <kbd>⏎</kbd> 保留所选主题，按 <kbd>Esc</kbd> 恢复原主题并返回之前的位置。

<a id="resuming-a-past-session"></a>
## 恢复历史会话

**会话**标签页列出编程智能体保存在本机上的会话，直接从各智能体自己的历史记录中读取：omp、pi、Kimi Code；OpenCode 2.x 与 Hermes 的历史通道按其正式适配与验收进度接入。读取只限受支持产品及有效作用域，不扫描退役产品的数据目录。

会话以你或智能体为其指定的名称显示；如果没有名称，则显示你最初提出的问题，同时列出运行目录、分支及上次使用时间。子智能体会话、已归档会话以及从未收到任何提问的会话不会显示。搜索会匹配标题、目录、分支和会话 ID。

按 <kbd>⏎</kbd> 会在会话原先运行的目录中打开一个新标签页，并在其中恢复会话（`omp --resume <id>`、`pi --session <id>` 等），同时使用 `agent_launch` 为该智能体提供的参数。智能体只能从其启动目录中找到会话，因此，如果会话目录已不存在，lyrel 不会恢复该会话，而是提示原因。

<kbd>⌘ E</kbd>（其他平台上为 <kbd>Ctrl E</kbd>）可打开该行的其他操作：

- **派生会话**——适用于支持派生的智能体；基于同一份历史记录开始新的对话
- **复制会话 ID**
- **从列表中移除**——隐藏该行（保存在 `config.json` 的 `hidden_agent_sessions` 中）；不会改动智能体自身的历史记录文件

在远程工作区中，该标签页会列出远程机器上的会话，恢复和派生操作也会在那台机器上打开标签页。这需要版本足够新、能够响应请求的 `lyrel-server`；较旧版本需要先更新。

搜索打开时，会在后台读取列表，因此刚刚启动的会话可能会比其他会话稍晚出现。Cursor 仅以哈希值记录聊天的目录，因此，只有当目录已在某个标签页中打开，或可从其他智能体的会话中获知该目录时，Cursor 聊天才会列出。

<a id="connecting-to-a-host"></a>
## 连接主机

在**主机**标签页中输入 SSH 地址，或直接在**全部**中输入，即可选择连接到该地址，或将其保存为主机：

```
me@devbox
me@devbox:2222
[::1]:22
```

也可以输入完整的命令行——`ssh -p 2222 -J jump me@devbox` 会严格使用这些选项进行连接，而 `ssh devbox` 会像 `ssh` 一样解析 `~/.ssh/config` 中的别名。单独输入一个不带其他内容的词会被视为搜索词，而不是地址。

已保存的主机按名称列出；在某个主机上按 <kbd>⌘ E</kbd> 会打开编辑界面，而不是连接。“操作”标签页中的 **SSH：添加连接…**会带你前往“主机”标签页。[SSH →](/remote/ssh)

<a id="sending-context-to-an-agent"></a>
## 向智能体发送上下文

以下两个操作会将你眼前的内容作为现成的提示词，交给窗格中正在运行的编程智能体：

- **智能体：发送选中内容**——当前选中的内容。
- **智能体：发送 Git 差异以供审查**——仓库的 `git diff`。

如果没有智能体正在运行，lyrel 会给出提示，而不会将内容输入到你的 shell 中。
