<a id="in-the-terminal"></a>
## 在终端中

<kbd>⌘ F</kbd> 会在当前聚焦的窗格上方打开查找栏，搜索该窗格的整个
回滚缓冲区，而不只是当前可见的屏幕内容。

| | |
|---|---|
| <kbd>⏎</kbd> · <kbd>⌘ G</kbd> | 下一个匹配项 |
| <kbd>⇧ ⏎</kbd> · <kbd>⌘ ⇧ G</kbd> | 上一个匹配项 |
| <kbd>Esc</kbd> | 关闭查找栏 |

查找栏中有两个开关：

- **区分大小写** — 默认关闭，因此小写查询也能匹配大小写不同的文本。
- **使用正则表达式** — 将查询作为正则表达式处理。如果表达式无效，
  会显示错误，而不是悄无声息地不匹配任何内容。

匹配项会在原位置高亮显示，逐个切换时，视图会滚动到相应位置。
在 Windows 上，使用 <kbd>Ctrl ⇧ F</kbd> 打开查找栏，
使用 <kbd>F3</kbd> 和 <kbd>⇧ F3</kbd> 切换匹配项。

<Tip>
  可搜索的内容量由**设置 → 终端 → 滚动 → 回滚缓冲区**决定：
  每个窗格默认为 10,000 行，最多可设为 100,000 行。更改仅对新建窗格生效。
</Tip>

<a id="everywhere-else"></a>
## 其他位置

lyrel 在许多位置都采用了相同的模式：输入即筛选，
无需按下任何按钮：

| 位置 | 搜索内容 |
|---|---|
| <kbd>⌘ P</kbd> | 命令，以及你完整输入的 SSH 地址 |
| <kbd>⌘ ⇧ O</kbd> | 工作区、标签页和机器 |
| <kbd>⌃ R</kbd> | 以模糊匹配方式搜索 shell 历史记录 — [参见历史记录](/terminal/history) |
| 设置搜索框 | 按名称和关键词搜索所有设置 |
| 文件面板 | 工作区根目录下的文件 |
| 主题选择器 | 内置主题和自定义主题 |
| 字体选择器 | 系统中安装的字体 |
