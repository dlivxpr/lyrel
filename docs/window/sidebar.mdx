title: "侧边栏"
description: "标签页自动按仓库分组，固定的分组始终位于上方，每一行都显示分支、差异计数和智能体状态。"
---

左侧边栏是 lyrel 的标签栏，默认采用这种布局，是因为纵向排列比横向标签有更多空间来展示信息：标签页所属的仓库、当前分支、其中有多少改动，以及其中的编程智能体正在做什么。

按 <kbd>⌘ B</kbd> 显示或隐藏侧边栏。拖动右边缘可调整宽度。

<a id="groups"></a>
## 分组

侧边栏会自动按仓库对标签页分组。你可以固定需要保留的分组。

**自动分组**位于固定分组下方。所有未固定的标签页都会归入其工作目录所在的 git 仓库——关联的工作树归入所属仓库，子模块单独成组——而 SSH 标签页则按连接的主机分组，因此两台机器上的 `/home/ubuntu` 会分属两个组。
其余标签页都会归入末尾的**未分组**区域。自动分组跟随标签页的工作目录，而不是它的历史记录：通过 `cd` 进入另一个仓库时，该行就会移动；切换分支则不会。当最后一个标签页离开后，该分组就会消失。

**固定分组**位于顶部，名称旁均有 ◆ 标记，按照你设定的顺序排列，直到你将其删除——空分组也会保留原位，并显示一行 **+ 新建标签页**。
固定分组中的标签页不会自行离开。固定分组有两种：

- **文件夹分组**关联一个目录。工作目录*进入*该文件夹的标签页会加入此组——包括在其中打开的标签页、通过 `cd` 进入该文件夹的标签页，以及该文件夹对应仓库的工作树中的标签页。当文件夹存在嵌套时，以层级最深的文件夹为准，因此同时固定一个 monorepo 及其中的某个包时，该包的标签页会归入包的分组。
  如果你在标签页仍位于该文件夹内时将其拖出分组，它会留在组外，直到离开该文件夹后再次进入。将指针悬停在分组标题上可查看文件夹路径；点击 ◆ 可取消固定，其标签页将回到自动分组。
- **标签分组**只有一个名称，用于归集那些因目录之外的原因而相关的标签页。标签页需要手动移入或移出此类分组。

固定分组的方法：

| 目标 | 操作 |
|---|---|
| 将自动分组变为文件夹分组 | 点击其标题上的 ◆，或将标题向上拖入固定分组区域 |
| 从文件夹创建文件夹分组 | 将文件夹从 Finder 拖放到侧边栏，在文件面板中对它选择**固定为分组**，或从全局搜索运行**将文件夹作为分组打开…** |
| 创建标签分组 | 右键点击标签页 → **移至分组 → 新建分组…**，或从全局搜索运行**新建分组** |

右键点击固定分组的标题，可以重命名、关联文件夹（**设置文件夹…**或**使用当前标签页的文件夹**）、清除关联的文件夹、在其中打开标签页，或删除分组。删除分组不会关闭任何标签页：其中的标签页会重新归入自动分组。自动分组无法重命名——需要先将其固定。标题上的 **+** 会在该分组的文件夹中打开标签页（标签分组则会在与 <kbd>⌘ T</kbd> 相同的位置打开），而 <kbd>⌘ T</kbd> 本身会让新标签页加入当前标签页所在的分组。

分组、排列顺序及折叠状态都随工作区保存，因此打开该工作区的每个窗口，以及下次启动时，都会显示相同的状态。

**设置 → 常规 → 自动分组**可以关闭自动分组。关闭后，未固定的标签页会以一个平铺列表显示在固定分组下方；固定分组则始终显示。

<a id="rearranging"></a>
## 调整排列

拖动一行可调整它在组内的顺序，拖动分组标题可移动整个分组——固定分组只能在固定分组之间移动，自动分组只能在自动分组之间移动。将一行拖到固定分组上可将其加入该组，拖到固定分组下方的任意位置则可将其交回自动分组。一行不能直接拖入自动分组：它的归属由工作目录决定，因此需要通过 `cd` 来移动它。

如果将一行拖出并移到窗格区域，它就不再是独立的会话：它会成为屏幕上当前标签页中的一个窗格，放置位置由高亮区域指示。反向拖动窗格——抓住其拖动手柄并拖到侧边栏——则会为它创建独立的一行，插入光标指示的两行之间。参见[将一个标签页变为另一个标签页的窗格](/window/tabs-and-splits#making-one-tab-a-pane-of-another)。

<a id="naming"></a>
## 命名

几乎所有标签页都没有专门设置的名称，因此侧边栏按以下顺序确定显示名称：

1. 你设置的名称（右键 → **重命名标签页…**）
2. shell 报告的标题——通常是正在运行的命令
3. 完全没有标题时，显示按位置编号的 **Shell 3** 等名称

`lyrel tab ls` 会用更多信息回答同一个问题，因为脚本没有屏幕可看。其 `label` 依次使用名称、标签页中运行的编程智能体（"omp"）、工作目录的最后一段、前台进程作为后备值——而 `name` 始终保留实际设置的名称，让脚本能够区分真正的名称与替代显示值。

<a id="the-switcher"></a>
## 切换器

<kbd>⌘ ⇧ O</kbd> 打开工作区切换器：左侧显示你已连接的所有机器上的全部工作区，右侧显示所选工作区的标签页。输入文字可同时筛选两侧，按 <kbd>⇥</kbd> 进入标签页列，按 <kbd>⏎</kbd> 打开。

你还可以在这里重命名工作区、在新窗口中打开工作区、停止工作区，或连接到已配置连接资料的机器。
