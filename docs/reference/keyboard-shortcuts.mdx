**设置 → 键盘与鼠标 → 键盘快捷键**（<kbd>⌘ ,</kbd>）是本页的实时版本——
它显示的是*你当前安装的应用*所使用的绑定。以下列出的是出厂默认值。

<a id="terminal"></a>
## 终端

| 操作 | macOS | Windows |
|---|---|---|
| 在终端中查找 | <kbd>⌘ F</kbd> | <kbd>Ctrl ⇧ F</kbd> |
| 查找下一个 · 上一个 | <kbd>⌘ G</kbd> · <kbd>⌘ ⇧ G</kbd> | <kbd>F3</kbd> · <kbd>⇧ F3</kbd> |
| 清除回滚缓冲区 | <kbd>⌘ K</kbd> | <kbd>Ctrl ⇧ K</kbd> |
| 复制 · 粘贴 | <kbd>⌘ C</kbd> · <kbd>⌘ V</kbd> | <kbd>Ctrl ⇧ C</kbd> · <kbd>Ctrl ⇧ V</kbd> · <kbd>⇧ Insert</kbd> |
| 插入换行（在提示符处） | <kbd>⇧ ⏎</kbd> · <kbd>⌥ ⏎</kbd> | 同左 |
| 模糊搜索历史记录 | <kbd>⌃ R</kbd> | 同左 |
| 接受幽灵文本建议 | <kbd>→</kbd> | 同左 |
| 补全菜单 | <kbd>⇥</kbd> | 同左 |

在 Windows 上，单独使用 <kbd>Ctrl V</kbd> 也可以在 shell 提示符处粘贴。
在全屏应用（vim、less、tmux）中，该组合键会原样传递给应用，
因此其含义由应用决定（在 vim 中为可视块模式）；在这些应用中，
请使用 <kbd>Ctrl ⇧ V</kbd> 或 <kbd>⇧ Insert</kbd> 粘贴。

这一便利功能对应的是**粘贴（全屏应用之外）**绑定，你可以自行更改。
清除此绑定后，<kbd>Ctrl V</kbd> 将在所有情况下交给 shell 处理，
包括 readline 的 `quoted-insert`：

```json
{ "keybindings": { "AlternatePaste": "" } }
```

反过来，将“粘贴”本身绑定到这个组合键，就会在所有屏幕中执行粘贴，
与 Windows Terminal 的默认行为相同：

```json
{ "keybindings": { "PasteText": "ctrl-v" } }
```

所有代表控制码的 <kbd>Ctrl</kbd> 组合键都会传递给正在运行的程序：
<kbd>Ctrl 6</kbd> 和 <kbd>Ctrl ⇧ 6</kbd> 对应 `^^`（vim 的交替文件），
<kbd>Ctrl /</kbd> 和 <kbd>Ctrl ⇧ −</kbd> 对应 `^_`（readline 的撤销），
<kbd>Ctrl 3</kbd> 对应 Escape。lyrel 保留的普通 <kbd>Ctrl</kbd> 组合键
都是不代表控制码的组合：<kbd>Ctrl ⇥</kbd> 用于切换到下一个标签页，
而在 Windows 上，<kbd>Ctrl +</kbd> · <kbd>Ctrl −</kbd> · <kbd>Ctrl 0</kbd>
用于调整字号。

<a id="rebinding-syntax"></a>
## 重新绑定语法

```json
{
  "keybindings": {
    "ResizePaneLeft": "ctrl-alt-left",
    "ToggleSftp": "secondary-shift-u",
    "ScmSync": "ctrl-b s"
  }
}
```

`secondary` 在 macOS 上表示 <kbd>⌘</kbd>，在其他平台上表示 <kbd>Ctrl</kbd>。
空格用于分隔多步快捷键的各个步骤。
