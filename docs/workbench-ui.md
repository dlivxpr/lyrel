# 工作台 UI 实现验收基线

本文记录已验收的交互和 UI，适用于会话历史、活动监视器、会话设置、顶栏资源、咖啡因和工具栏设置。实现前对照对应章节和 SVG，验收时使用真实窗口逐项比较。SVG 是布局、信息顺序及状态的基线，固定坐标和示例读数用于说明比例。实现中的缩放、配色、控件、间距和键盘行为沿用 [界面设计规范](design-system.md)。

## 侧面板 · 会话历史

![会话历史的单行布局和目录选择入口](images/workbench-session-history.svg)

- 「会话历史」是右侧独立工具。内容区顶部用一行展示「目录」标签、路径和下拉箭头，同一行只出现一次路径。工作树选择状态通过显示的路径表达。列表已有会话时直接显示结果，来源诊断留在没有结果的状态中。
- 列表复用「随处搜索」的紧凑单行布局，依次显示智能体标识、会话标题、相对时间。最近活动优先，选中行显示操作提示，路径不在列表行中重复。按键提示使用实际绑定。
- 默认按上下文窗格的主机和实际工作目录匹配会话。下拉菜单提供「跟随当前目录」和同一 Git 仓库的其他工作树目录。改选只刷新历史列表，选回跟随模式后继续随 `cd` 更新。
- 汇集 OpenCode、Oh My Pi、pi、Kimi Code 和 Hermes 可发现的原生会话。已打开的同一会话按主机、智能体、存储作用域和原生 ID 核验，点击定位到原窗格。
- 恢复其他会话时使用来源主机和目录。当前窗格确认处于空闲 Shell 时复用它。已有智能体会话、普通程序正在运行或无法确认空闲时，在当前窗格右侧创建窗格恢复。保持原窗格中的程序及待提交输入。

## 侧面板 · 活动监视器

![活动监视器默认状态，资源趋势默认 2 分钟，Lyrel 明细和窗格进程树均折叠](images/workbench-activity-monitor.svg)

- 「活动监视器」是右侧独立工具。原「信息」工具保留「会话」和「端口」两节，进程区域迁至活动监视器。
- 顶部标明当前窗格所在主机。资源磁贴默认可见，宽度充足时第一排依次是 CPU、内存、GPU，第二排是网络、磁盘。收窄时重排磁贴，保留标签和读数。
- CPU 和 GPU 显示利用率，内存显示已用量和总量，网络分别显示接收与发送速率。四项趋势共用 `2 分钟 / 15 分钟 / 1 小时` 选择器，默认 `2 分钟`。顶栏使用同一主机的采样。
- 整机 CPU、RAM 沿用按需约每秒一次的采样。切换时间范围只改变图表展示窗口。15 分钟和 1 小时视图按时间段汇总并保留峰值。历史保存在本次运行的内存中，未采样和断连的时段留空。硬件或平台缺少指标时显示 `—` 并说明原因。
- 磁盘按「当前目录大小 / 所在卷总量」显示，例如 `4.6 GB / 512 GB`，并标出被扫描的目录。读数来自最近一次完成的目录扫描。
- 资源磁贴使用中性标签，同排趋势图底边对齐。磁盘读数下方保留「目录大小 / 所在卷总量」说明，窄侧栏中允许说明换行。

### Lyrel 自身用量

![Lyrel 展开后按主机列出桌面界面、本机会话 daemon 和远端 Lyrel server](images/workbench-activity-monitor-lyrel.svg)

- 五块磁贴下放一行可展开的「Lyrel」摘要。默认折叠，显式标注 `CPU`、`RAM`、`GPU` 和所属主机。摘要统计本机桌面应用与本机会话 daemon。
- 展开明细逐行显示 CPU、RAM、GPU 和网络接收／发送速率。当前窗格涉及远程工作区时，在对应主机下另列 Lyrel server。本机与远端独立展示。Shell 和智能体等任务进程在窗格进程区查看。无法按进程取得的读数显示 `—`。

### 窗格进程

- 仅展示上下文窗格的进程树。默认折叠到 Shell 根行，显示折叠的子进程数量。展开后缩进展示父子关系，表头固定，PID、CPU 和内存数值右对齐。
- 支持按进程名或 PID 筛选，临时展开命中进程的上级路径。清空筛选后恢复原展开状态。按 CPU 或内存排序时只在同级进程内排序。自动刷新按进程身份保持选择。
- 进程行右键菜单提供「结束进程」与「结束进程树」。前者仅对目标发送结束请求，后者覆盖目标和其派生进程。确认界面列出目标与影响范围，影响范围由属主 daemon 按完整进程表计算，执行前重新核验每个进程身份和窗格归属，只结束确认清单内的进程并逐项报告结果。
- 无法确认归属的来源只供查看，且不出现结束动作：本机 shell 运行的 `ssh` 连接只展示本机一侧并明确标注，远端进程不可见；原生 SSH 窗格展示的是经 SSH 采样得到的远端进程列表，本机无法核验其身份，标注为采样来源；过旧的 daemon 无法说明会话位置时同样只读。嵌套 SSH 按最外层可用信息归类，仍然只读。

## 设置 → 会话

![A 版单条详情，左侧常驻会话列表与复选框，右侧常驻基本信息](images/workbench-session-settings.svg)

- 左侧为会话列表，右侧为常驻详情。打开设置时默认查看本机的所有目录，页头可切换到已连接的主机。切换主机后重新查看该主机的所有目录。
- 顶部按智能体、最近活动和目录组合筛选，并可搜索标题或原生 ID。时间选项为不限、最近 7 天、最近 30 天、早于 30 天及自定义日期范围。目录菜单提供「所有目录」与「选择目录」，分别通过本机系统选择器或所选 SSH 主机的目录浏览器选目录。
- 左栏以「会话」和「已隐藏」页签分组。点击标题打开单条详情，右栏展示标题、智能体、工作目录、最近活动、存储来源和原生 ID，并可复制 ID。阅读正文在智能体原生界面进行。

![会话多选，右侧清单标出暂不可删除的数量和逐条原因，删除按钮显示可删数量](images/workbench-session-settings-selection.svg)

- 每条会话的行首常驻复选框。复选框负责勾选，点击标题负责看详情。列表顶部的三态复选框只全选当前主机、当前页签、当前筛选结果中的记录。切换主机、页签或筛选条件时清空勾选。
- 勾选多条后，右栏切换为选中清单、取消选择和批量操作。「在 Lyrel 中隐藏」可从「已隐藏」重新显示。
- 选中清单先显示已知的暂不可删除数量，并在对应记录旁注明原因，例如「会话运行中」或「来源不支持删除」。删除按钮显示当前可删数量。点击按钮打开确认框，按重新核验的结果列出来源、目标、影响范围及被排除的原因。实际删除范围以确认清单为准。

## 顶栏资源指标

![标题栏右侧按钮组左边的 CPU、RAM 和 GPU 利用率指标](images/workbench-titlebar-metrics.svg)

- CPU 和 RAM 从底部状态栏迁至顶栏，GPU 同组加入。三项位于右侧分屏与面板按钮组左侧，依次展示标签、短趋势、当前值。CPU 和 GPU 使用百分比，RAM 使用已用容量。
- 资源指标胶囊与右侧按钮组之间留出 `0.75rem`。
- 数据跟随上下文窗格所在主机，与活动监视器共用采样。悬停可查看主机及详细读数，点击任一指标打开活动监视器。缺少读数时显示 `—`。
- 窄窗优先收起小图，保留数值、窗口拖动区域与原生窗口按钮。三项指标可在「设置 → 工具栏 → 顶栏」独立开关。

## 全局状态栏布局

- 全局状态栏高 `2rem`（默认缩放 32 px），内容左右内边距 12 px；编辑器面板自己的局部状态栏保持 `1.625rem`，两者可同时存在、上下相邻。
- 主机、路径、检出与分支、Git 改动数、运行程序各自使用浅中性药丸分组，药丸之间不再画分隔线；右侧咖啡因、时钟、通知为无底色幽灵控件，等宽数字时钟。
- 运行程序用药丸内的语义状态点（空闲中性、工作中强调色、完成绿、等待琥珀、失败红）加文字标签；有程序名时省略「程序」前缀。长路径或分支在药丸内截断，固定工具不被挤出窗口；浮动提示条停在全局状态栏上方 8 px。
- Git 改动数保持可点击打开「更改」；主机、路径、咖啡因、时钟、通知的可见性仍由「设置 → 工具栏 → 状态栏」各自开关。

## 状态栏 · 咖啡因

![咖啡因的关闭、始终开启和智能体工作时三种模式](images/workbench-caffeine.svg)

- 状态栏右侧用咖啡杯打开「咖啡因」菜单，选项为「关闭」「始终开启」「智能体工作时」。菜单勾选当前模式，底部文字显示是否正在保持唤醒。
- 杯子从请求的真实结果派生，共四种可见状态（#401）：正在保持唤醒（实际持有请求，含始终开启和自动模式工作期间）使用**填充杯**，着经对比度校验的主题强调色正文（`Neutrals::accent_ink`，各中性表面 4.5:1）；「关闭」与自动模式等待使用中性描边杯，等待时杯右下加小点；请求失败时使用描边杯并着 danger 角色，菜单底部与本机可访问名称给出失败说明。
- 控制的可访问名称同时包含所选模式与实际状态（标题、模式、状态一句），模式切换与实际持有/释放的结果一致。
- 自动模式等待任务时，咖啡杯使用中性色，有智能体工作时切换为强调色。所有智能体停止工作或进入人工等待状态后，颜色恢复中性并释放唤醒请求。自动模式可由本机或已连接远端上 Lyrel 中的智能体工作触发。
- 只保持运行 Lyrel 桌面的电脑免于空闲系统睡眠，屏幕照常熄灭和锁定。多个窗口共享模式，退出桌面应用时释放请求，重新启动时模式为「关闭」。

## 设置 → 工具栏

![工具栏设置分为顶栏和状态栏，咖啡因关闭时说明会停止保持唤醒](images/workbench-toolbar-settings.svg)

- 设置导航仅有一个「工具栏」入口。页内以细分隔区分「顶栏」「状态栏」两组，每行左侧是名称，右侧是即时生效的开关。
- 顶栏依次提供 CPU 利用率、RAM 用量、GPU 利用率。状态栏提供设置入口、主机、路径、Git 分支与改动数、运行状态、咖啡因、时钟、通知。Git 分支和改动数共用一个开关。设置快捷键继续可用。
- 关闭咖啡因组件开关会立即隐藏咖啡杯、停止当前模式并释放唤醒请求。重新显示时从「关闭」模式开始。

## 实窗验收

逐项比对上面的 SVG 和交互约定，分别记录 Windows、macOS 与需要的远程工作区场景。至少覆盖下列可见状态及其切换。

| 界面 | 应看到的变化 |
| --- | --- |
| 会话历史 | `cd` 更新目录和列表，选其他工作树只改列表。已打开、空闲、忙碌三个恢复场景各走对应路径。 |
| 活动监视器 | 2、15、60 分钟切换，首次采样、断连留空、目录磁盘更新、Lyrel 明细展开、进程树折叠和筛选、两个结束动作的确认范围。 |
| 会话设置 | 切换主机、日期和目录，检查单条详情、半选、全选、批量清单、暂不可删除的数量与逐条原因、隐藏与重新显示，以及原生删除确认时的重新核验。 |
| 顶栏与状态栏 | 检查浅色、深色、窄窗及界面缩放，指标与活动监视器读数一致，开关独立生效，原生窗口控件和拖动区可用。 |
| 咖啡因 | 对照上方四种状态与 SVG，在浅色、深色、代表性自定义主题和透明表面分别检查填充杯/描边杯、等待小点、danger 处理与可访问名称；再对照三个菜单模式检查自动模式在待机和工作间切换时的图标、状态文字及本机唤醒状态，最后检查工具栏关闭及重新打开。 |
