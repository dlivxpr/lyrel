**设置 → 键盘与鼠标 → 键盘快捷键**（<kbd>⌘ ,</kbd>）会列出应用中的每一个快捷键，
分组方式与全局搜索相同。设置顶部的搜索框
也能搜到这一页：输入功能的名称——`split`、
`commit`、`sftp`——页面就会缩小到与之相关的快捷键。操作名称
和标签一样可用于搜索，因此你在 `keybindings.json` 中看到的绑定，
搜索一次就能找到设置它的那一行。

## 重新绑定

点击一个快捷键，然后按下新的按键。最后一次有效按键后停顿 650ms，即结束录制并尝试保存；继续输入会延后提交。

| | |
|---|---|
| 按下按键 | 设置绑定 |
| 继续按键 | 串联一个序列——先 <kbd>⌃ B</kbd>，再按 <kbd>X</kbd> |
| <kbd>Esc</kbd> | 取消 |
| <kbd>⌫</kbd> | 删除最后一个键——或者作为第一个键按下，使该操作**不设快捷键** |

让某个操作保持未绑定，就是把按键交还给终端中正在运行的
程序：默认情况下 <kbd>⌥ 1</kbd>…<kbd>⌥ 9</kbd> 用于在标签页之间跳转，而
vim 想把它们用于自己的标签页。清除九个**跳到第 N 个标签页**行，
数字键就会直接透传。已清除的行会显示 `—`，并出现一个**重置**
按钮，用于恢复默认值。

如果录制的组合键已被另一操作占用，行内会先显示冲突与原操作名称，
只有点击**替换**才转移这个组合键；原操作的其他快捷键仍保留。
点击**取消**或按 <kbd>Esc</kbd> 不会安装候选绑定。
切换设置分区或关闭设置会终止录制，旧录制的延迟提交不能影响重新打开的设置。

实现上，`src/ui/settings/shortcuts/editor.rs` 的 `ShortcutEditor` 直接归属于独立设置窗口的
`SettingsState`，统一持有页内搜索、录制订阅、冲突、提示与 generation，并通过
`capture`、`commit`、`resolve_conflict` 和取消／退役接口维护这些转换。
窗口只适配 GPUI 输入与计时，接收已接受的 `ShortcutChange` 后仍走现有 `update_config`
保存和 `keymap::rebind` 路径；保存失败的 dirty、重试／放弃和跨页确认策略仍由设置协调层负责。
计时结果同时核对该页输入的 retained identity 与 generation，防止旧窗口会话或旧录制晚写；
退出时释放原订阅，不新建事件分发框架，也不改变焦点交接、预设、默认值或按键解释。

底部的**恢复全部默认值**会一次性撤销所有重新绑定。这个操作
无法撤销。

## 没有默认快捷键的操作

有些操作有意以未绑定状态发布，因为没有明显空余的按键
可用：窗格调整大小与交换、工作区选择、大多数 git 命令、SFTP，以及
右侧面板和设置分区导航。它们都出现在全局搜索中，也都可以在这里绑定。

## 导航区域的键盘入口

终端或编辑器持有焦点时，Tab 和方向键仍归内容所有。先通过下表操作进入导航区域；可在全局搜索中按名称执行，或在设置中重新绑定。

| 入口 | 操作名 | macOS | Windows／Linux |
| --- | --- | --- | --- |
| 聚焦终端标签侧栏 | `FocusTerminalTabNavigation` | <kbd>⌘ ⇧ L</kbd> | <kbd>Ctrl ⇧ L</kbd> |
| 聚焦右侧面板页签 | `FocusRightPanelNavigation` | 无默认绑定 | 无默认绑定 |
| 聚焦设置分区导航 | `FocusSettingsNavigation` | 无默认绑定 | 无默认绑定 |
| 聚焦左／右编辑器组 | `EditorFocusLeftGroup`／`EditorFocusRightGroup` | <kbd>⌘ ⌥ ←</kbd>／<kbd>⌘ ⌥ →</kbd> | <kbd>Ctrl Alt ←</kbd>／<kbd>Ctrl Alt →</kbd> |
| 聚焦当前组的文档标签 | `FocusDocumentTabNavigation` | <kbd>⌘ ⌥ T</kbd> | <kbd>Ctrl Alt T</kbd> |
| 打开全部文档列表（`+N`） | `EditorDocumentOverflow` | <kbd>⌘ ⌥ ⇧ T</kbd> | <kbd>Ctrl Alt ⇧ T</kbd> |

终端标签侧栏入口只展开侧栏并聚焦当前可见标签或其分组标题，不切换会话。搜索、设置、关闭确认、切换器、worktree 提示或文档前置层打开时，该入口不抢占焦点；编辑器文本中的 <kbd>⌘ ⇧ L</kbd>／<kbd>Ctrl ⇧ L</kbd> 仍归 `SelectAllOccurrences`。文档标签入口要求代码面板已可见且存在文件，不会替你打开面板。

进入后遵循各区域的键盘契约：

- 每个导航组只有一个 roving Tab 停靠点。Tab 离开组，Shift+Tab 按该组的 roving 停靠点返回，不在每项之间逐项遍历。
- 右侧面板和文档标签用 Left／Right，设置分区和终端标签侧栏用 Up／Down；方向键只移动焦点并回绕，Home／End 到首尾，不会激活另一页、会话或文档。
- Enter／Space 手动激活焦点项并保留导航焦点。终端侧栏的分组标题通过同一按键折叠或展开；指针激活仍按既有行为把焦点交给内容。
- Escape 在导航自身持有焦点且没有上层覆盖层时返回所属内容：右侧面板回到进入前焦点，设置回到当前页面而不关闭设置，终端侧栏回到活动 pane，文档标签回到当前组文本。Escape 是各表面的局部行为，不是可重新绑定的独立 action。
- 终端侧栏只遍历可见分组标题和标签，折叠项不占用停靠点。关闭或重排后按稳定身份保留有效焦点，不会顺带激活另一会话。
- 共享文档标签跟随聚焦编辑器组，并分别记住各组焦点。`+N` 列表可输入过滤，Up／Down 移动高亮，Enter 选择并聚焦文本，Escape 按打开来源返回文档标签或文本；不增加文档标签滚动或文档拖拽。

## 改为编辑 `config.json`

```json
{
  "keybindings": {
    "NextTab": "ctrl-alt-]",
    "SplitRight": ["cmd-d"],
    "ResizePaneLeft": "ctrl-alt-left",
    "ToggleFullscreen": ""
  }
}
```

一个操作的值采用两种形式之一：

| 值 | 含义 |
|---|---|
| `"ctrl-alt-]"` | **添加**此快捷键。默认值继续有效——<kbd>⌃ ⇥</kbd> 仍会打开标签页切换器 |
| `["cmd-d"]` | **替换**：仅这些快捷键，不保留其他快捷键。列出多个即可拥有多个 |
| `""` 或 `[]` | **取消绑定**该操作 |

在设置页面录制快捷键属于替换，因此会写入列表
形式。你添加的快捷键如果已被另一个操作使用，实际生效的是你添加的
这个。例外是终端自身的快捷键：终端获得焦点时，复制、粘贴、查找、
清除回滚缓冲区和插入换行仍使用各自的快捷键。

lyrel 从 `0.1.0` 起采用上述规则。旧产品的快捷键配置不会自动读取或迁移；在 lyrel 中录制快捷键会写入列表并替换默认值。直接编辑配置时，如需替换默认值，请使用列表，例如 `"NewTab": ["cmd-shift-n"]`。

语法是修饰键以 `-` 连接，然后是按键。多步组合键之间用
空格分隔。

| 标记 | 含义 |
|---|---|
| `secondary` | macOS 上为 <kbd>⌘</kbd>，其他平台为 <kbd>Ctrl</kbd> |
| `cmd` · `ctrl` · `alt` · `shift` | 字面修饰键 |
| `ctrl-b n` | 一个两键序列 |

若要把某个按键留给终端中正在运行的程序，请取消占用它的操作
绑定。例如 vim 的标签页按键：

```json
{
  "keybindings": {
    "ActivateTab1": [], "ActivateTab2": [], "ActivateTab3": [],
    "ActivateTab4": [], "ActivateTab5": [], "ActivateTab6": [],
    "ActivateTab7": [], "ActivateTab8": [], "ActivateTab9": []
  }
}
```

未知的操作名称、无效的按键，或者既不是快捷键也不是快捷键列表的
值，都会被跳过，并在日志中记录一条警告，而不会破坏你其余的
绑定。

完整的操作列表见[键盘快捷键](/reference/keyboard-shortcuts)
页面。

## tmux 预设

**设置 → 键盘与鼠标 → 键盘快捷键 → 预设 → tmux** 会把窗格和标签页操作重新映射到
前缀键上——默认是 <kbd>⌃ B</kbd>，可在旁边的**前缀**字段中
更改。

| | |
|---|---|
| <kbd>⌃ B</kbd> <kbd>C</kbd> · <kbd>X</kbd> | 新建标签页 · 关闭标签页 |
| <kbd>⌃ B</kbd> <kbd>%</kbd> · <kbd>"</kbd> | 向右拆分 · 向下拆分 |
| <kbd>⌃ B</kbd> <kbd>←→↑↓</kbd> | 移动焦点 |
| <kbd>⌃ B</kbd> <kbd>⌃ ←→↑↓</kbd> | 调整窗格大小 |
| <kbd>⌃ B</kbd> <kbd>O</kbd> · <kbd>;</kbd> | 下一个窗格 · 上一个窗格 |
| <kbd>⌃ B</kbd> <kbd>&#123;</kbd> · <kbd>&#125;</kbd> | 与上一个窗格 · 下一个窗格交换 |
| <kbd>⌃ B</kbd> <kbd>Z</kbd> | 缩放窗格 |
| <kbd>⌃ B</kbd> <kbd>N</kbd> · <kbd>P</kbd> | 下一个标签页 · 上一个标签页 |
| <kbd>⌃ B</kbd> <kbd>1</kbd>…<kbd>9</kbd> | 跳转到某个标签页 |

两个让它经得起日常使用的细节：

- **单独按前缀键**约一秒后会传给 shell，所以当你的本意就是
  “回退一个字符”时，<kbd>⌃ B</kbd> 仍然有效。
- **前缀键加上未绑定的按键**会直接透传给终端，因此你未重新映射的
  tmux 绑定仍会送达到正在运行的程序中。

## 一些不那么直观的默认值

| | |
|---|---|
| <kbd>⇧ ⏎</kbd> · <kbd>⌥ ⏎</kbd> | 在提示符处插入换行，而不是提交（`InsertNewline`） |
| <kbd>⌘ ⇧ ⏎</kbd> | 缩放当前聚焦的窗格 |
| <kbd>⌘ ⇧ E</kbd> | 切换代码面板 |
| <kbd>⌘ ⇧ R</kbd> | 重启此窗格中的 SSH 会话 |
| <kbd>⌘ ⇧ O</kbd> | 工作区切换器 |
| <kbd>⌘ ⇧ N</kbd> | 新建工作区 |
