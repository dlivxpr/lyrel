**设置 → 键盘与鼠标 → 键盘快捷键**（<kbd>⌘ ,</kbd>）会列出应用中的每一个快捷键，
分组方式与全局搜索相同。设置顶部的搜索框
也能搜到这一页：输入功能的名称——`split`、
`commit`、`sftp`——页面就会缩小到与之相关的快捷键。操作名称
和标签一样可用于搜索，因此你在 `keybindings.json` 中看到的绑定，
搜索一次就能找到设置它的那一行。

## 重新绑定

点击一个快捷键，然后按下新的按键。稍作停顿后即会保存。

| | |
|---|---|
| 按下按键 | 设置绑定 |
| 继续按键 | 串联一个序列——先 <kbd>⌃ B</kbd>，再按 <kbd>X</kbd> |
| <kbd>Esc</kbd> | 取消 |
| <kbd>⌫</kbd> | 删除最后一个键——或者作为第一个键按下，使该操作**不设快捷键** |

让某个操作保持未绑定，就是把按键交还给终端中正在运行的
程序：默认情况下 <kbd>⌥ 1</kbd>…<kbd>⌥ 9</kbd> 用于在标签页之间跳转，而
vim 想把它们用于自己的标签页。清除九个**跳到第 N 个标签页**行，
数字键就会直接透传。已清除的行会显示 `—`，并出现一个**重置**
按钮，用于恢复默认值。

底部的**恢复全部默认值**会一次性撤销所有重新绑定。这个操作
无法撤销。

## 没有默认快捷键的操作

有些操作有意以未绑定状态发布，因为没有明显空余的按键
可用：窗格调整大小与交换、工作区选择、大多数 git 命令、SFTP，以及
面板标签页。它们都出现在全局搜索中，也都可以在这里绑定。

## 改为编辑 `config.json`

```json
{
  "keybindings": {
    "NextTab": "ctrl-alt-]",
    "SplitRight": ["cmd-d"],
    "ResizePaneLeft": "ctrl-alt-left",
    "ToggleFullscreen": ""
  }
}
```

一个操作的值采用两种形式之一：

| 值 | 含义 |
|---|---|
| `"ctrl-alt-]"` | **添加**此快捷键。默认值继续有效——<kbd>⌃ ⇥</kbd> 仍会打开标签页切换器 |
| `["cmd-d"]` | **替换**：仅这些快捷键，不保留其他快捷键。列出多个即可拥有多个 |
| `""` 或 `[]` | **取消绑定**该操作 |

在设置页面录制快捷键属于替换，因此会写入列表
形式。你添加的快捷键如果已被另一个操作使用，实际生效的是你添加的
这个。例外是终端自身的快捷键：终端获得焦点时，复制、粘贴、查找、
清除回滚缓冲区和插入换行仍使用各自的快捷键。

lyrel 从 `0.1.0` 起采用上述规则。旧产品的快捷键配置不会自动读取或迁移；在 lyrel 中录制快捷键会写入列表并替换默认值。直接编辑配置时，如需替换默认值，请使用列表，例如 `"NewTab": ["cmd-shift-n"]`。

语法是修饰键以 `-` 连接，然后是按键。多步组合键之间用
空格分隔。

| 标记 | 含义 |
|---|---|
| `secondary` | macOS 上为 <kbd>⌘</kbd>，其他平台为 <kbd>Ctrl</kbd> |
| `cmd` · `ctrl` · `alt` · `shift` | 字面修饰键 |
| `ctrl-b n` | 一个两键序列 |

若要把某个按键留给终端中正在运行的程序，请取消占用它的操作
绑定。例如 vim 的标签页按键：

```json
{
  "keybindings": {
    "ActivateTab1": [], "ActivateTab2": [], "ActivateTab3": [],
    "ActivateTab4": [], "ActivateTab5": [], "ActivateTab6": [],
    "ActivateTab7": [], "ActivateTab8": [], "ActivateTab9": []
  }
}
```

未知的操作名称、无效的按键，或者既不是快捷键也不是快捷键列表的
值，都会被跳过，并在日志中记录一条警告，而不会破坏你其余的
绑定。

完整的操作列表见[键盘快捷键](/reference/keyboard-shortcuts)
页面。

## tmux 预设

**设置 → 键盘与鼠标 → 键盘快捷键 → 预设 → tmux** 会把窗格和标签页操作重新映射到
前缀键上——默认是 <kbd>⌃ B</kbd>，可在旁边的**前缀**字段中
更改。

| | |
|---|---|
| <kbd>⌃ B</kbd> <kbd>C</kbd> · <kbd>X</kbd> | 新建标签页 · 关闭标签页 |
| <kbd>⌃ B</kbd> <kbd>%</kbd> · <kbd>"</kbd> | 向右拆分 · 向下拆分 |
| <kbd>⌃ B</kbd> <kbd>←→↑↓</kbd> | 移动焦点 |
| <kbd>⌃ B</kbd> <kbd>⌃ ←→↑↓</kbd> | 调整窗格大小 |
| <kbd>⌃ B</kbd> <kbd>O</kbd> · <kbd>;</kbd> | 下一个窗格 · 上一个窗格 |
| <kbd>⌃ B</kbd> <kbd>&#123;</kbd> · <kbd>&#125;</kbd> | 与上一个窗格 · 下一个窗格交换 |
| <kbd>⌃ B</kbd> <kbd>Z</kbd> | 缩放窗格 |
| <kbd>⌃ B</kbd> <kbd>N</kbd> · <kbd>P</kbd> | 下一个标签页 · 上一个标签页 |
| <kbd>⌃ B</kbd> <kbd>1</kbd>…<kbd>9</kbd> | 跳转到某个标签页 |

两个让它经得起日常使用的细节：

- **单独按前缀键**约一秒后会传给 shell，所以当你的本意就是
  “回退一个字符”时，<kbd>⌃ B</kbd> 仍然有效。
- **前缀键加上未绑定的按键**会直接透传给终端，因此你未重新映射的
  tmux 绑定仍会送达到正在运行的程序中。

## 一些不那么直观的默认值

| | |
|---|---|
| <kbd>⇧ ⏎</kbd> · <kbd>⌥ ⏎</kbd> | 在提示符处插入换行，而不是提交（`InsertNewline`） |
| <kbd>⌘ ⇧ ⏎</kbd> | 缩放当前聚焦的窗格 |
| <kbd>⌘ ⇧ E</kbd> | 切换代码面板 |
| <kbd>⌘ ⇧ R</kbd> | 重启此窗格中的 SSH 会话 |
| <kbd>⌘ ⇧ O</kbd> | 工作区切换器 |
| <kbd>⌘ ⇧ N</kbd> | 新建工作区 |
