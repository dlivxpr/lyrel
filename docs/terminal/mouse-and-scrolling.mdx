## 滚动

滚轮和触控板用于滚动窗格的回滚缓冲区。相关设置都在**设置 → 终端 → 滚动**下：

| 设置 | 默认值 | 作用 |
|---|---|---|
| **回滚缓冲区** | 10,000 行 | 每个窗格保留多少历史记录，最多 100,000 行。仅对新窗格生效。 |
| **滚动速度** | 1.0 | 滚轮滚动的倍数（0.1–10）。 |
| **平滑滚动** | 开启 | 将每一格滚轮滚动在几帧内平滑到位，而不是一次跳到终点。触控板本身就会连续滚动，不受影响。 |

滚轮只负责滚动。如果想同时用它缩放字体，请在**设置 → 终端**下选择一个修饰键（或设置 `mouse_zoom_modifier`）；<kbd>⌘ +</kbd> / <kbd>⌘ −</kbd> 无论哪种方式都能缩放。

视图一开始移动，窗格右边缘就会出现滚动条，停止移动后它会淡出——与侧边栏以及应用中所有列表使用的是同一款滚动条。拖动滑块可一次跨越整个回滚缓冲区，点击轨道则可跳转。处于实时输出边缘的窗格始终不显示滚动条，无论其中有多少输出在流动。

触控板在手势开始时锁定“滚动还是缩放”，该决定持续到惯性尾段结束；中途按下或松开修饰键不会把同一次手势改成另一种操作。新手势会重新判断。滚轮则逐格判断修饰键；一次滚轮缩放只改变一级字号，触控板缩放会累计移动量后按整级改变。

### 稳定阅读与回到实时输出

离开实时输出后，窗格以绝对行身份保留阅读位置。首次滚动捕获一屏活动文字的语义内容；读取到的历史行按首次取得的内容保留，因此后台程序使用光标定位、擦除或重画活动屏幕时，不会改写当前阅读的文字。程序、PTY、daemon 和桌面终端镜像仍继续推进，并未暂停输出。

文字区域底部居中的按钮显示 `↓ N 行 · 回到实时输出`（英文界面为 `↓ N lines · Return to live`）。数字表示距实时边缘的行数，不是未读消息数；不足一行的滚动向上取整。后台产生更多历史行时，距离随之增长。点击按钮，或在阅读时按 Tab 聚焦按钮后按 Enter，会通过原有回到提示符路径返回实时输出，并把焦点交回终端；Enter 不发送给子进程。直接输入或粘贴也保留原有返回实时输出的行为。滚回实时边缘会释放阅读内容，下次离开时重新捕获当前文字。

按钮使用标准 `Button` 的语义主题、键盘焦点和缩放尺寸；它不增加终端行数，底部位置避开已测量的 composer、补全及反向搜索浮层。窄窗格中标签可以省略，完整文案保留在辅助功能名称与 tooltip 中。

这里的文字实现属于 #251。图片及选择／复制／链接／搜索的同源交互由 #252 接入；resize 逻辑行重定位由 #253 接入；清屏／reset／重连世代及隐藏窗格生命周期由 #254 完成。不要把基础文字阅读消费者当作这些后续行为或 #255 原生桌面验收的通过证据。


### 实现职责

`src/terminal/selection_scroll.rs` 的 `SelectionScroll` 统一持有选择拖拽、越界自动滚动、平滑动画、手势锁定，以及彼此独立的滚动／缩放余量。它借用现有 live grid，由私有 `reading.rs` 保存绝对 top row、一屏解码后的活动 cells 以及首次读取的必要历史行，不克隆整个 grid，也不创建额外 entity、锁或 daemon 行获取协议。样式保存 ANSI 值、字符、marks、hyperlink 和宽字符／换行语义，不保存可回收的 side-table ID 或主题解析色；每帧沿用同一颜色解析逻辑。`TerminalView` 适配 GPUI 事件、原有帧回调／定时器、viewport 上报和字号 action；滚动条仍经原有 handle 提交目标行。回到提示符时使用同一所有者释放阅读内容、取消动画并清除行内余量。同步输出 hold 与长期阅读是独立机制：未提交的同步帧不会被捕获为阅读内容。绘制及命中仍使用 `TerminalElement` 最近一帧的逻辑像素 cell geometry；display scale 只用于向子进程报告设备像素。

滚动条在实时边缘仅冻结供显隐判断的呈现几何，仍记录最新历史范围；拖动目标不能使用旧的或空的历史容量来裁剪。目标经同一 `SelectionScroll` 路径进入阅读并捕获行，粘贴仍通过原有路径释放阅读态。每个保留行还保存共享 Kitty 解码器取得的 placeholder runs；完整行及分数滚动的上一行图片切片都与冻结文字使用同一行来源，不从后台已改写的 live cells 重新推导。这项接线修复不替代 #252 的完整图片 lease 与同源交互验收。

消费者回归集中在 `selection_scroll_consumer_tests.rs`，规则回归在 `selection_scroll_tests.rs`。原生验收仍需在 live terminal 上执行拖选／越界滚动、输出期间反向扩选、滚轮／触控板惯性尾段修饰键切换、拖动滚动条，以及窗口 resize 和界面／显示缩放；自动断言不能替代这些平台交互记录。

`reading_consumer_tests.rs` 增加受控真实 PTY → 隔离 daemon → `RemoteTerminal` → 生产 `TerminalView` 的文本回归，以及标准 GPUI Button 的位置、Tab／Enter、点击、双语、窄窗格与界面缩放测试代码。本工单实施阶段按集成约定未执行构建、测试或格式化；集成人应运行以下命令并保留原始结果，不能把已添加测试写成已通过：

集成首轮 `reading_` 记录为 `3 passed / 1 failed`：滚动条在实时边缘冻结的旧历史范围阻止了阅读态建立。修复后增加离开实时画面的断言、历史增长后的滚动条目标回归，以及活动 placeholder cells 被擦除后的生产图片绘制回归；本修复子任务按约定未执行测试、构建或格式化，不能把新增断言计为通过。

```powershell
cargo test --locked -p lyrel --lib terminal::view::gpui_tests::reading_ -- --nocapture --test-threads=1
cargo test --locked -p lyrel --lib terminal::view::gpui_tests::selection_scroll_consumer_tests:: -- --nocapture --test-threads=1
cargo test --locked -p lyrel --lib terminal::view::gpui_tests::synchronized_ -- --nocapture --test-threads=1
cargo test --locked -p lyrel --lib ui::i18n::tests::every_key_is_translated_in_every_locale -- --exact --nocapture --test-threads=1
cargo fmt --check
```

上述 GPUI 测试观察生产绘制输入、控件布局和测试平台输入事件，不是原生 GPU 像素、系统 IME、触控板惯性或真实 SSH 验收。#255 仍须分别记录桌面本地开发与桌面远程开发的实窗结果。


### 同步输出的呈现边界

终端收到 synchronized update 开始标记后，文字、光标、模式及 daemon 图片状态仍立即解析；桌面继续绘制上次已提交的完整文字／光标／图片画面。焦点、主题、光标闪烁或其他重绘不能把中间状态带入该画面。结束标记或距最近开始标记 150 ms 的 fail-safe 解除暂停；即使此后完全没有 PTY／网络字节，reader 也会推进期限并使新帧可发布。

实际 resize／reset、命令结束、replay 建立基线及链路退出会结束旧的呈现暂停，避免旧期限跨重连或重挂载遗留。键盘和应用鼠标协议仍读取实时模式；本地选择、复制、链接命中及 IME 的终端光标位置以已呈现内容为准。暂停期间不自动滚入尚未发布的隐藏内容；新帧发布后恢复普通 live-grid 交互。图片资源和 placement 仍只有 daemon 一个权威，桌面持有的是同一预算内、无像素复制的上一帧呈现 lease。

生产 `Root`／`TerminalView` 回归检查真实 paint 消费的 cells、caret、图片和复制结果，并另测无后续输入的期限推进；reader 回归检查分片、协议与受控的 150 ms 边界。测试窗口不是原生像素／IME 或真实 SSH 的证明；完整 Kit／Fast／Rio 组合的 Windows／Linux／macOS 与性能结果分别记录，macOS 仍需 #167 实机验收。

### 真彩色样式与历史容量

当前终端内核为正式 `rio-vt 0.5.29`。每个 grid 的同时保留样式容量约为 65k，屏幕和历史共同占用名额；超限时新样式可能回退默认前景色，字符仍会保留。这是已知的限定容量差异，不表示普通真彩色输出必然触发。

内核的 mark-and-sweep 会回收不再被引用的样式，但主屏连续滚动时，逻辑历史之外的 raw 缓存行也可能保留样式引用。因此，调小回滚缓冲区不能保证避免颜色回退；不能把已有 GC 描述为样式容量无限，也不能通过丢弃输出或擅自缩短历史掩盖该限制。


## 指针

在**设置 → 键盘与鼠标 → 鼠标**下：

| 设置 | 默认值 | 作用 |
|---|---|---|
| **焦点跟随鼠标** | 关闭 | 悬停在窗格上即可聚焦，无需点击。 |
| **输入时隐藏鼠标** | 开启 | 打字时指针消失，下一次移动时重新出现。 |
| **向应用报告鼠标事件** | 开启 | 全屏程序——vim、tmux、`htop`——会自行接收点击和滚动事件。按住 <kbd>⇧</kbd> 可让手势保持在本地，改为选择文本。 |

<Tip>
  如果在 `vim` 或 `less` 中选择文本时抓到的是应用自己的选择而不是你的选择，请在拖动时按住 <kbd>⇧</kbd>。
</Tip>

应用的拖动和松开报告只属于实际向该应用报告过按下的窗格。从侧边栏、标题栏或其他窗格开始的拖动不会进入本窗格；在本窗格开始的应用拖动可以越过边界，坐标限制在原窗格边缘，直到松开。按住 <kbd>⇧</kbd> 开始的本地选择不会因中途松开修饰键而变成应用拖动；本地松开或下一次无按键的指针移动会清理旧手势所有权。普通点击、滚轮和应用请求的无按键移动报告保持原有规则。
多个按钮同时按下时，左键、中键和右键分别保留自己的已报告按下；松开一个按钮不会丢弃其他按钮的松开报告。无按键移动统一清理所有旧手势，避免丢失跨窗口松开后留下所有权。

`src/terminal/mouse_reporting_consumer_tests.rs` 通过生产 `Root`／`TerminalElement` 的鼠标事件路由、隔离 daemon 和真实 PTY 子进程读取应用收到的字节，检查跨窗格所有权、修饰键变化、丢失松开以及正常点击／滚轮。它不替代 Windows／macOS 原生窗口的拖动和跨窗口松开验收。

### 链接的实现职责

`src/terminal/link.rs` 的 `LinkInteraction` 是链接状态的唯一所有者，持有悬停范围、修饰键状态、Host／目录上下文、探测缓存、请求 epoch 和右键按下时捕获的目标。`src/terminal/view/links.rs` 是私有 GPUI adapter：将 hover、probe、菜单和 activation 接到同一所有者，为它提供 pane 的 Host／cwd 与配置，并执行通知、剪贴板、URL 打开或 `OpenFileRequested` 导航事件。根视图继续保留终端 attachment、焦点身份和跨能力生命周期，不向链接能力暴露整个可变视图，也不新增 entity 或锁。

右键菜单使用捕获的 Host、路径和行列位置，不在菜单绘制或激活时跟随新指针重新选择目标。远端文件始终交给内置导航；系统默认应用与显示所在文件夹只接受本地目标。终端内再次 SSH 到其他机器时，不用桌面的文件系统解释那台机器的路径。URL 与文件保留各自的打开策略，loopback URL 继续使用现有转发路由；关闭链接检测、全屏程序的修饰键要求，以及鼠标报告模式下的 Shift 覆盖规则均不变。

adapter 通过 `HostOps` 在后台执行 Host 的目录根查询和远端文件探测。返回结果先同步当前上下文，再由 `LinkInteraction` 的 epoch 检查决定是否接受；Host／目录或网格变化后，已退役的结果不能替换新交互的 hover 或菜单目标。实体关闭后的回调、失败通知及后续焦点交接仍遵循原有 GPUI／工作台生命周期。

消费者回归位于 `src/terminal/view/links/consumer_tests.rs`，覆盖 pane cwd、远端隔离、延迟结果、菜单捕获身份、resize、换行与宽字符命中；确定性状态规则仍位于 `src/terminal/link/tests.rs`。原生验收须使用隔离配置，在实际终端上检查 URL、含行列的本地文件、目录与远端文件的 hover、修饰键点击、右键菜单、复制路径和导航后的焦点；Windows、macOS 与真实 SSH 的结果分别记录，自动测试不替代这些运行证据。

## 字号

| | |
|---|---|
| <kbd>⌘ +</kbd> · <kbd>⌘ −</kbd> | 放大 · 缩小 |
| <kbd>⌘ 0</kbd> | 恢复为配置的字号 |
| <kbd>⌘</kbd> + 滚轮 | 在终端上滚动以缩放 |

基础字号由**设置 → 外观 → 终端文本 → 终端字号**决定，默认为 15 px。界面的其余部分有各自的字号——**界面字号**，默认为 16 px，可在 12 到 24 之间调整——因此你可以单独缩放界面外观而不影响终端网格，反之亦然。

## 响铃

**设置 → 终端 → 响铃 → 终端响铃**决定 `^G` 的行为：

| 模式 | 行为 |
|---|---|
| **关闭** | 无任何效果 |
| **视觉** *(默认)* | 短暂闪烁 |
| **声音** | 系统声音 |
| **两者** | 闪烁并发出声音 |

## 命令完成通知

**设置 → 常规 → 通知**会在前台命令完成时弹出桌面通知：

- **命令完成时通知** — *从不*、*未聚焦时*（默认）或 *始终*
- **通知阈值** — 命令需运行多久才触发，默认为 10 秒

编程智能体也采用相同的策略来处理自己的通知。
