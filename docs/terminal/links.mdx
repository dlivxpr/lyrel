按住 <kbd>⌘</kbd>（Windows 上为 <kbd>Ctrl</kbd>），指针下方的链接就会显示下划线；单击即可打开。

稳定阅读时，URL、OSC 8 hyperlink 和文件路径的命中来自已呈现的冻结行；后台将同一位置改写成另一个链接，不会改变当前点击目标。滚动或返回实时输出会使旧几何和未完成的探测请求失效，文件解析仍遵循该 pane 的 Host／cwd。搜索同样以阅读行覆盖实时匹配，修改查询或切换上／下一项不会把 live 中的新词高亮到旧文本上；未捕获的历史仍由原有终端搜索读取。

<a id="urls"></a>
## URL

任何看起来像 URL 的内容都会被检测到，即使 shell 将其换行显示在两行中也不例外——lyrel 会在打开前将其重新拼接起来。

HTTP(S) 链接默认在侧面板的「浏览器」打开。点击时再按住 <kbd>Shift</kbd>，可在系统浏览器中打开。

可通过**设置 → 终端 → 链接 → 检测 URL**
（`link_url: false`）关闭检测。

<a id="files"></a>
## 文件

普通文件链接默认进入 Lyrel 编辑器，可定位到指定的行列。文件面板打开时会选中文件。目录链接会转到文件面板中的目录。

支持 `path:line`、`path:line:column`、`path(line,column)` 和 `path#Lstart-Lend` 等位置写法。智能体输出的 `path:start-end` 范围引用会打开范围的第一行，例如 `src/main.rs:12-18` 定位到第 12 行；范围后缀不会作为文件名的一部分。

绝对路径和相对路径都能被检测到。解析相对路径时，会先以窗格的工作目录为基准，再以该目录所在的仓库为基准。因此，即使 shell 位于某个成员目录中，也能正确解析构建工具以工作区根目录为基准输出的路径。如果这两个位置下都找不到匹配的路径，lyrel 会给出提示，而不是毫无反应。

连接到另一台机器的窗格中的路径会*在那台机器上*解析，因此下划线会在指针停稳片刻后出现，而不是立即出现。如果窗格是在本地 shell 中输入 `ssh` 后运行的会话，就没有可为其解析路径的主机，因此其中的文件链接会被禁用。

**设置 → 终端 → 链接 → 文件打开方式**决定单击后如何打开文件：

| 模式 | 打开方式 |
| --- | --- |
| 内置编辑器 | 在 lyrel 编辑器中打开，并定位到 `:line:column`。这是默认选项。 |
| 默认应用 | 使用操作系统为该文件类型关联的应用打开。 |
| 命令 | 使用你自定义的命令——见下文。 |

远端普通文件在工作台内打开，使用所属 Host 的路径。没有行列后缀的 `.html`、`.htm` 和 `.xhtml` 链接可进入 [HTML 预览](/window/side-panel#browser)，加按 <kbd>Shift</kbd> 可改用系统浏览器。本机「命令」模式仍优先使用配置的命令。

选择**命令**时，运行命令前会替换其中的占位符：

```
code --goto {path}:{line}:{column}
zed {path}:{line}
herdr edit {path} --line={line}
```

`{path}`、`{line}` 和 `{column}` 的值会从链接中提取。如果某个选项的值不可用，就会移除该选项，而不是传入空值——因此，当链接没有行号时，`--line={line}` 会直接被省略。

对应的设置项是 `config.json` 中的 `link_file_open`（可取 `internal`、`system` 或 `command`）和 `link_file_command`。在引入 `link_file_open` 之前编写的配置仍然有效：已设置命令的配置会继续使用**命令**模式，未设置命令的配置则会改用内置编辑器。

<a id="localhost-ports"></a>
## localhost 端口

按住 <kbd>⌘</kbd>（Windows 上为 <kbd>Ctrl</kbd>）点击 `localhost:3000`。对于可转发的远端窗格，Lyrel 会按窗格路由建立或复用转发，再打开浏览器。

此功能默认启用；通过**设置 → 终端 → 链接 → 转发远程端口**
（`ssh_loopback_forward`）可将其关闭，同时也会关闭对远程窗格开始提供服务的端口的自动转发。

<Tip>
  受管理的远程工作区可在「信息」中列出已采样的监听端口。原生 SSH 窗格可手动转发已知端口。参见[端口转发](/remote/port-forwarding)。
</Tip>
