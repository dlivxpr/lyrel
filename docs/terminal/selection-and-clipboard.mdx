## 选择

| | |
|---|---|
| 拖动 | 选择一段范围 |
| 双击 | 选中光标下的内容——见下文 |
| 三击 | 选中整行 |
| <kbd>⇧</kbd>-单击 | 将当前选择扩展到单击处 |
| <kbd>⌘ A</kbd> *(macOS)* | 全选——也位于右键菜单中，并在所有平台的全局搜索中提供 |

### 智能双击

双击并不只是抓取由空格划界的单词。它会判断你正指向什么：

| 光标下的内容 | 得到的结果 |
|---|---|
| URL | 完整的 URL——包括被 shell 折成两行的那个 |
| 文件路径 | 完整路径 |
| 电子邮件地址 | 完整地址 |
| 括号或引号 | 与之配对的那一个，以及两者之间的全部内容 |
| CJK 文本 | 按词典而非按字符切分出的词语 |

可通过**设置 → 键盘与鼠标 → 选择与剪贴板 → 智能选择**将其关闭。
关闭后，双击会退回到普通按词选择，使用 `config.json` 中的
`word_separators` 列表——默认值如下：

```
,│`|:"' ()[]{}<>⇥
```

## 复制与粘贴

| | macOS | Windows |
|---|---|---|
| 复制 | <kbd>⌘ C</kbd> | <kbd>Ctrl ⇧ C</kbd> |
| 粘贴 | <kbd>⌘ V</kbd> | <kbd>Ctrl ⇧ V</kbd> · <kbd>⇧ Insert</kbd> |

有两项设置决定剪贴板中最终得到什么，二者都位于**设置 → 键盘与鼠标 →
选择与剪贴板**中：

<CardGroup cols={2}>
  <Card title="选中即复制" icon="clipboard">
    用鼠标选中后立即复制，无需按 <kbd>⌘ C</kbd>。默认关闭。
  </Card>
  <Card title="复制时去除行尾空格" icon="scissors">
    去掉每一行复制内容末尾的空白——从按窗格宽度补齐空格的 TUI 中
    复制时很有用。默认关闭。
  </Card>
</CardGroup>

<Note>
  粘贴多行内容时，会将其作为键入输入发送，与任何终端的行为一致。
  如果 shell 支持方括号粘贴，它会将整块内容视为一次粘贴，而不是逐行执行。
</Note>
