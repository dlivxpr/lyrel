# 工作事项与规格

仓库不预设本地工单目录，也不要求每项任务生成规格、地图或实施票。

## 读取与记录

- 用户提供工单、规格路径或外部链接时，先读取其实际内容；不猜测编号或自行生成目录。
- 会话内的执行步骤使用任务列表跟踪。长期有效的行为、维护约束和未验收边界更新到对应正式文档。
- 只有用户明确要求创建文档或发布工单时，才按其指定位置记录；目标位置不明确且会影响交付时再询问。
- 用户选择本地 Markdown 工单时，沿用该文件已有的 `Status:`、评论和依赖关系约定；需要分诊标签时查阅 `docs/agents/triage-labels.md`。
- 已完成的任务记录实际结果与证据边界；部分成功、前提缺失和未验证项不能写成完成。
